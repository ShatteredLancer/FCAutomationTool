# X 采集器后台运行

## 已确认的操作合同

- 桌面三个入口：启动、查看状态、停止。启动后没有常驻黑窗口；关闭管理提示不停止后台进程。
- 不安装系统服务、计划任务或开机自启；仍只有用户点击采集按钮才调用 Grok。
- 重复启动复用现有服务，不产生第二个采集器；状态检查不采集、不消耗额度。
- 停止只通过本机认证接口关闭本采集器；正在采集时取消自己的 Grok 子进程，不按进程名批量结束 Node。
- 保留配对码、设置、锁卡和所有交易记录；重启无需重新配对。采集中停止可能已有模型费用，不承诺撤销已发出的模型调用费用。
- 保留原前台命令供排查。旧版服务缺少停止接口时明确提示，不误报已停止。

## 本轮计划及验收

1. 新增隐藏、脱离启动终端的启动器及认证停止接口；验证无采集冷启动、重复启动、停止后重启、错误密钥、端口冲突和采集中取消。
2. 新增桌面快捷方式安装器及交易页停止按钮，明确后台启动/状态/停止用法；离线浏览器验证忙碌时可停止、配对保留及窄屏。
3. 完整测试、构建与 ad 最新 main 比较；本机安装快捷方式并验证实际后台进程/停止/重启；不执行任何 X 采集或 EA 交易。
4. 提交并推送 main，核验公开版本与哈希。真实油猴新版按钮验收与离线浏览器检查分开记录。

当前：实现及本机后台生命周期验证完成。桌面 `FCAT X Collector` 的 `Start Collector`、`Collector Status`、`Stop Collector` 已安装；使用 ASCII 路径避免本机 WSH 对中文快捷方式路径的保存失败。原前台窗口由用户关闭后，已真实验证隐藏启动、状态、重复启动、认证停止、停止后离线及重启（当前空闲运行），全程没有 X/Grok 调用。
