## 事实与已批准行为

11:26:31 导出日志最后一次交易事件仍为 09:58:05Z 的 HTTP 403 / MARKET_THROTTLED，之后没有新启动或原生买入诊断。截图同时显示两个已停止任务与共享暂停；日志不含停止动作和任务快照，不能据此认定是谁点击停止或哪一层停止标记生效。旧实现 stopRequested、任务 stopped 或持久化 clock.stopped 任一均禁止启动；解除共享暂停不改变这些状态。

## 实施步骤与验收

1. 已停止且无未决回执的任务可编辑。增加显式重新开放入口，在同账号 owner/native/task 锁内核对最新 revision、未知交易、共享暂停与原累计时间限制，只撤销任务停止标记及对应时钟停止位，不重置计数或租期费用。
2. UI 显示 Restart 和 Edit；确认说明保留累计记录。重新开放成功后才按原 run/enqueue 通道启动；若中途取消或页面切换，最多留下暂停任务，不产生隐式买卖。已有其他任务运行时复用当前 owner 的短控制轮次，忙则明确提示重试，不重建执行器。
3. 修正共享暂停文案，不再无依据归因于其他 FCAT 入口。全局解除、只读核对、保存与刷新均不自动重新开放或启动停止任务。
4. 回归覆盖：旧 stopped/stopRequested/仅 clock 停止；已确认持仓与支出保留；未知回执/共享暂停/累计时间上限；修改上限后恢复；陈旧快照/账号变化/重复点击/写失败/恢复中再次停止；另一任务运行时加入；原停止与只读核对不复活；桌面和窄屏 UI。执行完整 verify、离线 Chrome，并安装最终构建。真实交易仍由用户点击。
