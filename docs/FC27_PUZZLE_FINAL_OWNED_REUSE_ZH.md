# Puzzle 最终概念阵容的库存替换（2026-11-08）

## 现场与已确认目标

用户反馈 Road to the Knockout Challenge 1 填阵后，在 Requirement Met 中仍出现库存替代卡。截图选中53分概念铜卡 García，列表展示60分 Tarnutzer、63分 Maas，显示价均200，显示替换后的化学17/15。列表本身不能证明它们通过FCAT的FSU、锁卡、主阵容、其它SBC预留、同源估价和全部原生条件；不把截图价当作本轮FUTBIN价格，也不根据列表推断它们已被实际选用。

00-40-01诊断版本标为27.0.100，但已包含30秒可选优化截止的本地修复特征，不能只靠版本号宣称用户未更新。目标103/154实际concept-filled、保存核验成功；总79725ms，规划76251ms，查价68075ms（库存45101ms、市场22999ms），搜索6735ms。方案4库存＋7待购，材料3000、待购1400，七张待购各200，主源FUTBIN。309个自有版本中250有价（9铜/50银/191金）、59未报价，材料目标保持material-value并标记覆盖不完整。两页目录/10000累计节点，最终因可选优化时间到而保留基线。截图全队3100不能直接与不同时间/来源的日志3000混为同一价格。

沿用已确认目标：最低材料总价值先比较库存估值＋采购额，同材料价值时优先更少待购；最低新增支出仍优先减少待购。不为了少买卡消耗估值更高的库存，也不把不可交易卡或未知报价当免费。

## 已复现问题与实施

1. 单卡替换的等价预过滤只允许品质下降，漏掉同价同品质的概念→库存。即使最终比较器把现金作为第二目标，这种候选也根本进不了完整验算。Club/Storage合成回归先失败，修正后11000材料保持、1000待购降至0；真实原生评分/化学/规则仍验算。
2. 局部替换针对进入搜索的旧阵容，后续全局搜索获胜的混合阵容并没有保证再做同样检查。生产Session冻结一个合规全局赢家作边界回归，旧流程10200材料/1200采购/2概念，新流程10200材料/200采购/1概念，最终conceptPlan同步；不是现场逐卡重放。
3. 在最终返回、概念保存前新增一次仅概念→安全库存的单卡检查。复用已经报价的候选和原生验证，不读新目录、不查新报价、不再进行全阵或双卡搜索。最多1600替换节点＋1次基线验证，消耗原剩余节点；原额度耗尽则跳过，不扩大50k/200k或原报价范围。
4. 该有界收尾位于可选目录优化结束之后，因此30秒仍仅指可选探索，不是含查价/验证/保存的整轮上限。已有取消/上下文变化立即停止；最终报价有效期/定向重核及保存前材料鲜读保持。剩余采购只保留原赢家的子集及其原引用、时间和限价。
5. 仅影响普通Puzzle本轮新方案。Gallery、Streamlined、买卡重试/交易Journal、已有保存阵容恢复不改；不会更新脚本就自动替换已填好的卡。
