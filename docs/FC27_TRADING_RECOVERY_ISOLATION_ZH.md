# 交易未决记录恢复与隔离

2026-11-18：本页累计实现纳入 [27.0.114](releases/27.0.114.md)，下文“不升版提交”为当时记录，不代表当前提交状态。

2026-11-16，本地 27.0.110；承接挂牌回执核对修复。用户要求未决记录必须有明确恢复出口。

## 操作流程

1. 在“市场交易”点击“核对交易回执”，根据精确实体及当前原生回执恢复。
2. 若旧记录仍不能确认，展开“交易恢复”，对发送满一分钟的记录点击“隔离旧记录”，阅读确认窗口后执行。
3. 隔离仅改变本地阻断范围，不清除原记录、不证明成交或失败，也不自动解除暂停。用户单独点击“解除全局暂停”，通过当前会话核验后，再明确启动其他任务。
4. 隔离任务及其卡片仍受保护；未知买入／竞价仍计入资金、持仓与未来容量，并阻止其他任务重复购买同版本。其他不相关任务可运行。
5. 用户在游戏或原生页面手动处理后，可点击“已手动处理（备注）”。备注不是 EA 回执，不释放未知资金；点击“重新核对”，取得精确证据后才解除相应保护。

这里解除的是 FCAT 本地暂停，不能解除 EA 登录失效、验证或市场限制。某条记录始终没有可核验的结果时，仍隔离保留，不以“没找到卡”推断未成交。

## 实现边界

- Journal 新增 `isolated` 状态，保留原意图、金额、确认标记和所有持仓。隔离时间及手动备注只保存在本账号原账本内，无新存储键。
- 操作绑定账号及账本 revision，要求显式批准、空闲调度器、账号 owner 和原生锁。保存后完整回读；过期窗口、其他 owner、存储失败、停止或账号变化不会产生新的 EA 写入。
- 调度、provider、最终写入预留及持仓移交分别保留保护；不能通过旧快照、重新启动、换任务或同版本新挂单绕开。
- 只读恢复同时核对 pending 与 isolated；确切成交／未挂牌证据沿用原核验，不伪造回执。隔离后的核对失败不会仅因该记录存在而重新阻断所有任务，认证／限流错误仍共享暂停。
- 恢复列表每页五条，显示任务、动作、公开版本、金额、时间与状态。确认可取消；不会在刷新、翻页或关闭窗口时交易。
- 保护范围为 FCAT 市场任务调度器；不宣称能阻止其他插件或用户手动操作。
