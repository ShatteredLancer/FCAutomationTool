## 实施步骤 / 验收

1. 先建立失败回归：公共参考请求固定空收藏、响应/平台/账号边界；参考组合本地验分/扣已有；整体已知组合不重复跑逐档深搜；单合集生成中同语义重绘后结果不丢失。
2. 只读服务固定两个公开端点、匿名/限长/超时/无自动重试、每平台短期内存缓存与pending合并，失败不拖垮原本地规划，不新增GM大对象。
3. 显示公共D–S参考表和来源/时间/非个人费用；严格映射后作为本地核验候选。参考价不写入现有报价/购买审批；按原价格来源重新查价。
4. 快速首轮优先核验这些完整组合，剩余深度搜索可明确选择，保持部分覆盖/非最优标记。先展示公共参考，避免所有信息都等EA全目录同步后才出现；记录阶段耗时。
5. 指定档位结果首个候选默认展开；保存同合集同语义的进行中规划表面，筛选/排序重绘不丢结果。真实数据/账号/目录变化仍取消并明确提示，不重复交易。
6. 全量verify、全套离线Chrome、公开输入只读回放、主线差异/版本/产物校验，提交推送并核验公开下载hash。用户账号不买卖/移卡/领取。
