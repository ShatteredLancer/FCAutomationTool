# 审核后自动执行的交易方案

Sam 当前确认：先给综合结论及可审核清单，上限可调，当前以 20,000 金币试仓；用户看过并点击确认后，自动按方案买入、移到转会列表、按目标价上架。不能只提供只读行情或让用户先填球员。

## 合同与实施顺序

1. 用现有有界候选生成整批方案：精确版本、数量、买入硬上限、固定卖价、5% 税后情景收益、风险和退出条件。首版每个版本一张、最多六张，不要求用满预算；总上限及留存金币可编辑。
2. 方案由当前账号/报价及设置绑定。单源或已过期的候选只观察，不冒称可立即买到。启动前必须有可信点击；更新、开页、重启、采集 X 都不启动交易。
3. 新独立执行服务复用原生购买、转移、挂牌适配器，不改 Gallery/SBC/Streamlined 事务。只处理本方案新购且有精确实体证据的卡，绝不出售现有 Club 卡或清除任何旧待核对记录。
4. 买入前冻结总上限/单卡上限/卖价并持久回读；成交/转移/挂牌不明先核对，不重复发送。认证、限流、验证码、余额/容量不足立即暂停。无低价挂单则跳过，不抬价或换卡。
5. 买入后自动上架；上架不代表成交或盈利。只读核对精确挂牌/成交；过期不自动降价。停止阻止新操作，保留在途证据和已购持仓；原有 EA 挂单不会撤回。页面离开/刷新不自动继续，需用户明确恢复。
6. 完整验证后按默认方式推送 main。不在用户账号执行真实交易代替测试，也不承诺不封号或保证收益。

当前：实现及离线贯通完成，新增 EVO 消息仓见 [27.0.98](releases/27.0.98.md)，原交易台整理和过期恢复见 [27.0.97](releases/27.0.97.md)。背景采集器仅采集 X，与 EA 自动交易运行/停止分别控制。

## 当前入口

打开“交易观察”后，默认进入“投资与执行”：设置本轮总上限/最低留存 → 生成清单 → 审核逐卡买入上限、目标挂牌价和情景净利 → 勾选 → 确认启动。过期整批候选最多重新分析一次，重新审核，不续用旧审批。

“候选与线索”查看分析和显式采集 X；“观察笔记”只保留旧观察/手填功能；“设置”管理观察条件和本机采集器配对。两种账面额度分开标明。继续旧方案使用该方案冻结的原上限/留存，不以新输入偷偷改动旧审批。

EVO 消息仓：在“候选与线索”粘贴单条帖子 → 读取/核价 → 纳入整批 → 返回重新生成并审核。消息仓先持有，在本页运行且触价授权有效时，到冻结目标后上架；六小时后暂停复核，不自动降价止损。重载/离页/账号变化取消授权。推算目标不是未来行情预测，来源作者的低风险主张不是安全保证。

## 已验证场景

- 整批审核：可调总额/留存、单卡上限/税/利润缓冲、精确版本、已有手填持仓扣额、移除候选重算；无合格双源候选明确不生成。
- 权限边界：不准备/不勾选/不确认不交易；页面/X刷新不下单，跨账号拒绝，重开保留记录不继续。
- 原生贯通：实际原生买入适配器与移库/挂牌/售出读取接口使用合成运行时走通，分别验证精确实体、固定价格、挂牌非收益、独立读回。
- 防重：未知买入/上架跨停止/重载/恢复不重发；丢写不付款；明确未发送停止可继续；未知业务拒绝不连打；旧 Gallery/原生待核对 Journal 保留且挡住新任务。
- 故障：余额/占用/容量、报价变动、错误实体/超价、核限价时 401/403/429/503、上架回读丢失后只读恢复；这些不放宽限价或制造成功。
- 浏览器：置顶结论、完整表格、二次确认、逐卡进度、停止/重开及桌面/390px；没有真实 EA 网络写入。
