本记录区分历史工程约束、当前功能支持范围和账号事务保护。测试里的常量不是平台限制；新增功能需要更新相应合同，不能为了满足旧测试而撤回合理功能，也不能通过删除账号保护让测试通过。

## 本次调整：取消固定 150,000 字节上限

来源是首版提交 `675d937`（2026-09-18）新增的 `tests/contracts/fc27-production.test.js` 和 `tests/contracts/fc27-acceptance.test.js`，各有一条 `manifest.bytes < 150000`。当时 27.0.0 的说明把约 130 KB 作为精简结果；没有找到 150,000 字节对应的平台限制或性能测量依据。

新增 Puzzle 规划接线后本地生产构建为 214,409 字节，原构建为 143,673 字节。这个增长本身不能证明性能退化，也不构成撤回功能或改为远程加载的理由。本次删除两条上限断言，改为验证 manifest 字节统计与实际 UTF-8 产物一致且非空；同时移除 Preview 90,000 和传统事务核心 25,000 字节上限。Puzzle 生产接线未撤回。后续评估同时观察依赖来源、重复代码、初始化耗时、规划时延和 UI 响应。
