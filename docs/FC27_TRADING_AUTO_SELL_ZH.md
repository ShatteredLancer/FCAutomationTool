# 按评分自动出售持仓

2026-11-18：本页累计实现纳入 [27.0.114](releases/27.0.114.md)，下文保留各阶段验证记录；实盘连续出售仍按已列边界由用户启用验收。

2026-11-17，本地 27.0.110；用户要求保存评分规则，持续发现并挂牌新入库的可交易卡，无需每次手动选卡。

## 使用方式

在市场交易中新建“持仓出售”任务，出售选卡方式选择“按评分自动出售（持续检查）”。最低、最高都填写 88 即只匹配 88 分；也可设置范围。仓库可选全部、Club、Transfer、Unassigned。设置固定卖价或参考价比例、挂牌时长及原有重挂规则，保存后明确启动。

启动后首次读取实际持仓，之后每轮扫描结束五分钟后再次检查。发现新卡即按保存的卖价规则加入原任务队列。没有匹配卡时等待下一轮，不把任务标成完成；暂停、停止、刷新或关闭 Web App 后不会自行恢复。定时任务仍等待卖出开始时间；运行上限及认证、未决交易等既有停止条件继续生效。

“读取缓存持仓”仅是编辑时预览，不限定自动任务的执行名单。保存或预览本身不会移卡或挂牌。手动模式另加最低／最高评分及全选／取消匹配卡，跨五条分页选择，仍只保存明确的最多 500 张实体卡。

## 实现与保护

- 可选 `sellSelection` 配置保存在原账号任务中，旧任务默认仍是手动名单；编辑、复制、重开及配置变更检查保留该字段。自动范围必须明确，空评分不默认扩为全库。
- 扫描复用已审查的库存／Club transport。先鲜读 Transfer 与 Unassigned，Club 按 250 张分页，验证页长、重复实体和扫描前后人数；不把缓存或部分页当完整扫描结果。每次读取前检查取消与账号，仍走原生锁和原有请求间隔。
- 每次扫描只在当前运行的 provider 保存临时候选，不把整库写入 GM。旧候选未完成核验时不移交账本；失败不回退到缓存继续出售。
- 可交易、非活动挂牌、非 EVO／租借／学院／概念卡条件，以及原锁卡、主阵容、其他流程预留保护均保留。其他市场任务已持有或隔离的实体不会被本任务重新认领。
- Club／Unassigned 卡先使用原流程移到 Transfer 后挂牌；Transfer 匹配卡直接走原挂牌流程。认领、移动、挂牌及最终发送前都检查同一实体与评分范围；认领后移仓不使原授权失效。
- 各任务仍由原账号调度器串行操作，共享原买卖／搜索限额。库存读取不是市场搜索，不消耗市场搜索计数；五分钟是本地轮询策略，不宣称 EA 允许的安全频率。
- 已确认持仓使用原挂牌／未售回读／重挂逻辑，未知结果保留并暂停，扫描不产生重复挂牌或自动清理旧记录。原账本容量上限继续有效。
