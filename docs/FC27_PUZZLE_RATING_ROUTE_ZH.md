# Puzzle 有评分要求的补卡查询（27.0.58）

## 需求、证据与范围

2026-10-24 .57 诊断的 Set 59/Challenge 99：合规库存 0，三页查询均为铜卡，
公开候选 25/可用 24，50,000 节点耗尽；再次点击使用相同缓存并从头搜索。
补充截图确认：Barcelona OR Real Madrid 至少 2 人、同国至少 3 人、同俱乐部最多 4 人、
至少 4 联赛、整队最低 75、化学最低 26、11 人，没有品质限制。

当前 generic route 在品质无约束时先按低品质排序，两条俱乐部锚点和普通补位占满三页，
使查询范围全是铜卡。截图不是完整 EA DTO；测试 fixture 只转录已审查的字段，球员/阵型/价格另造。
不把合成解当作真实市场可买或全局最低价。

## 计划与不变量

1. 先运行真实 route/shortage/Session 边界失败回归，证明评分 75 仍只查询铜卡。
2. 补卡只读查询在品质条件允许时，优先覆盖能够达到整队评分下限的品质；只改变查询排序，
   不把低品质卡从求解候选中删除、不把球队评分条件变成每张卡评分下限。
3. 保留明确品质/数量合同、个人最高评分、FSU、锁卡/主阵容、特殊卡、报价/预算及未知交易保护。
4. 仍最多三页/每页 20 个版本、累计 50,000 节点；保留材料总价值目标与完整规则/化学验算。
5. 完整测试、离线 Chrome、版本/产物/上游复查后按已有发布方式提交并推送 main。

本次不重构持久化搜索游标，不以扩大节点数掩盖错误卡池，也不执行真实购卡、保存或提交。
