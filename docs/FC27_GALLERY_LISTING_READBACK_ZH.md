## 硬边界与恢复行为

- 未决 intent 在发送前持久化，成功回执在回读前持久化；核对器不调用 list/move/permit。
- 同一 exact item 不因换批次而释放；unknown/缺失/已移除不等于失败，不自动重上架。
- active 仍要求原精确字段；closed 额外要求成功 2xx 回执，不能仅凭过期/消失清记录。
- closed 仅显示“已挂牌（拍卖已结束）”，不宣称售出或记销售收入。
- 401/403/427/429、验证码、权限/会话失败停止只读重试；原交易停止/冷却逻辑不变。
- 读回即使标成 completed，若携带 HTTP 408/5xx/明确失败响应，也不使用缓存实体确认；只允许有界只读重试。
- Stop/账号变化不发送下一张；写入/复读失败不继续后续卡。
- 历史记录不清空。已确认卡刷新/重新核对不会再次上架；其余只按原授权继续。
- 诊断仅固定 mismatch、次数、HTTP 状态和计数，不导出物品/账号/拍卖标识。
