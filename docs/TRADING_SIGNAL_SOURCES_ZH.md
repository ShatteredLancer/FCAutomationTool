## 拓展优先级

1. **正式需求层**：EA 已公布的 SBC 需求和完整 EVO 条件，记录发布日期、到期、精确卡版与真正合格名单。不能把过去 FC26 的说明页冒充当前 FC27 活动。参考 [EA Evolutions 说明](https://help.ea.com/en/articles/ea-sports-fc/ultimate-team-evolutions/)、[FUT.GG EVO 目录](https://www.fut.gg/evolutions/)及[FUTWIZ EVO 目录](https://www.futwiz.com/evolutions)。这些页面的存在不表示本插件已经自动接入。
2. **市场背景层**：大盘/评分档位指数、逐卡历史分位、源价更新时间，判断是个别需求还是整盘波动。可参考 [FUTBIN Market](https://www.futbin.com/market)；必须确认赛季/平台和数据窗口，未知成交量保持未知。
3. **预期及反证层**：扩展原帖、作者回复和交易讨论，区分首发/搬运/个人持仓推销；同时收集供应增加、替代卡、EVO 条件不匹配等反证。更多人重复一句话不是多份独立证据。
4. **决策输出层**：每条建议回答“催化是什么 → 为什么是这一版本 → 当前价格是否已反映消息 → 最高买价/固定卖价 → 税后情景收益 → 失效条件”。不把模型补充推断写成检索事实。
