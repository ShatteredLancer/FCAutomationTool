- 用户 .71 导出保留一次单合集 A 档成功记录：33 候选、31 报价、目标 1100、找到 1125 分/31650 金币；不是所有单合集调用都失败。其他失败末尾未保留，未证明每次都是同一根因。

- 原回放：`node artifacts/gallery-71-club-refresh-repro.mjs` 红；加 `--control` 绿。用合成卡/报价，未连接 EA 或行情服务。
