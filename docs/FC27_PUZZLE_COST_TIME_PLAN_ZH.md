# Puzzle 材料价值与耗时联合调查（2026-11-07）

## 结论

当前不是单纯“节点不够”或“网络慢”。已经能找到合规阵容，但可选降价工作存在重复读取和搜索，长时间运行后报价失效又丢弃结果，造成等得久且材料仍贵。优先消除无效工作、保留完成的改进，再评估搜索策略，不能靠扩大预算或简单减少搜索来宣称解决。

本轮不升版、不提交；版本仍为本地27.0.100。以下分清已实现与后续建议，不将计划写成已完成。

## 后续适合的方案及实施顺序

### 第二步：同成本结果提速，先量化再改算法

- 对同一冻结候选/价格/规则，记录有效计算、上下文检查、等待、完整阵容验算次数与重复率。固定现有节点和候选，比较耗时与最终成本，先确认第一步能解决多少。
- 只在同一冻结输入内编译俱乐部映射、化学配置和单卡谓词；当前完整评估器会重复解析这些不变量。保留最终独立完整验算，输入变化立即失效。需差分证据再接入，不全局缓存可变EA实体。
- 测量历史方向评估和正常本地搜索的重复组合；对相同精确候选、站位、规则缓存结果或续用搜索进度。不能仅按球员版本缓存，因为库存实体、保护和报价可能不同。
- 查价现在已经只读所选主源，不能再建议“去掉双源查询”来解释这轮。优先复用有效公共缓存/批量报价；在原250范围内按原阵、合法低价替换和必需身份覆盖分层，逐层完成就推进计算。缺价明确不参与金额比较，未知不能补0；不要仅选最低评分而丢失必要化学连接。

### 第三步：更低材料价值的有界搜索

- 目标沿用用户设置：最低材料总价值＝库存估值+待购总额；最低新增支出＝待购总额优先。库存不可交易不等于材料价值0；金/银只是品质，不能代替真实金币价。
- 先检查当前阵容的单卡降价，按位置保留覆盖；再搜索能同时保住俱乐部/联赛/国籍/化学关系的双卡交换。单张替换不成立不等于组合不存在。
- 针对仍昂贵的局部结构尝试小范围重新组合（例如3–4槽），而不是每次重搜11槽。按候选带来的成本下降及约束连接排序；它是有界启发式，保留必要锚点和原完整验证，不能宣称全市场最优。
- 每次得到新解立即作为本轮基线；后续只能按相同目标改善，超时保留最佳。真实价格变化则重新比较，不能要求旧价金额机械单调。
- 仅在局部优化无进展且仍有时间时进入全局分支定界。用乐观成本下界剪去不可能更便宜的分支，不能用未经证明的化学估计删候选。无需优先增加50k/200k节点；更多节点会掩盖低效遍历。

### 第四步：可见的成本—时间选择

- 进度显示阶段、累计耗时、已查价/候选数、当前最佳材料价值、待购总额和铜银金数量。完成表示“当前已找到”，不要用未枚举全市场的百分比冒充最优进度。
- 普通填阵有明确可选优化时间；“继续深度降价”作为后续可选功能，在原输入仍有效时继续本轮进度，不重做已完成工作。进入保存/购买仍走原验证与授权边界。
- 冷缓存网络耗时与热缓存计算耗时分别验收。先记录第一步修复后的真实阶段时间，再确定体验目标；不承诺所有SBC固定秒解。

## 验收标准

- 同一输入/同一报价，成本不得劣于修复前已验证基线；已知可单卡或双卡降低的控制必须找到替换。
- 低品质可行且更便宜时有正确选择；必需金卡、最高评分、锁卡、FSU、主阵容、其它SBC预留仍严格生效。
- 真正无法满足的池仍拒绝；时间到与证明无解分开，不为了快保存不合规阵容。
- 热/冷缓存各测159–162，在相同政策和预留下比较阶段耗时、材料价值与现金支出；专用浏览器97安全卡的旧只读结果不能当现场291卡重放。
- 无真实买卡/清阵/移卡/保存/提交由自动检查触发；待用户正式重新填阵后读取诊断核验实机成本与时间。
