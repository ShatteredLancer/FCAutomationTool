这个例子为什么需要联合规划？
  • 俱乐部集合可用 A＋B 或 E＋B；联赛集合可用 A＋C 或 E＋F；稀有度集合需要 C＋D。这些组合仅为预设的虚构可行方案。
  • 俱乐部单独买 E＋B 最便宜，但 A 同时帮助联赛；先独立选各集合最低价、最后才去重，也可能比联合选择更贵。
  • 缺一组中的任意卡都没有该组奖励，因此逐张按“即时奖励 / 价格”贪心会漏掉解。
  • 本演示只有六张虚构卡，可以检查全部 64 种子集得到精确结果。生产计划采用有界搜索和规则复核，不穷举真实全卡库，不承诺全局最优。
  • 报价变化后只展示重新计算的方案；生产执行不得据此突破用户批准的候选范围或预算，已花费与未知扣款仍需保留。
