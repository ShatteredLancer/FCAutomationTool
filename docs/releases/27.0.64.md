# 27.0.64 — Public Gallery references, faster first pass and visible grade results

- Overall Gallery planning now reads Fodder's public catalog and all-set proposals with a fixed anonymous empty-collection request. No actual collection, First Owner facts, account identity, Fodder authentication or EA credentials are sent. It uses the existing permitted domain, no reverse proxy or new persistent GM payload.
- Shows a separate D–S public cost table before the full EA collection sync finishes. These are empty-collection purchase estimates, not personal missing-card costs, revolving capital or spending caps. The source does not provide the age of the underlying market observations; that remains unknown.
- Defaults to a **fast first pass** when compatible public proposals are available. It quotes only their missing versions through the existing price service, verifies the exact local versions and current scoring rules, deducts collected history and removes redundant purchases. Unknown collection facts, missing prices, foreign versions and per-card capital limits remain conservative. Uncovered targets are explicitly pending, not impossible. **深度优化** retains complete-candidate quoting and the original bounded search. A more expensive public proposal never replaces a cheaper local result.
- Keeps the whole-Gallery route, cross-set reuse, revolving-capital/loss distinction and existing collection execution handoff. It adds visible elapsed time by public reference/sync/pricing/planning phase and allowlisted reference/timing metadata to the local analysis export.
- Fixes a reproduced single-collection UI failure: filtering while pricing rebuilt the detail DOM and discarded the in-flight result. Semantically identical redraws now retain the running planning surface; genuine data changes still cancel it. The selected grade is frozen during calculation, and the first successful result is expanded and brought into view.
- Existing purchasing, listing, quote authority, per-card/total budgets, locks, active-squad protection and pending transaction journals are unchanged. Public references neither trade nor authorize spending.

Verification: full `npm run verify` passed (436 files, 5,202 passed, 39 skipped); build/root-dist/version and FSU assets verified. Twelve new unit tests cover the public protocol, strict joins, privacy, cache/platform/context boundaries and conservative local verification. Offline Chrome covers early reference visibility while EA sync is held, fast route/handoff, filtering during pricing, expanded results, Stop, expiry, account isolation and existing workflows.

Public-input CPU replay: with the same captured San Diego card pool and controlled prices taken from the public response, a three-second bounded deep run remained partial; quick local verification took about one millisecond and retained the same known 5,800-coin/5-token candidate. This is **not** an end-to-end speedup claim, independent live quote verification, the user's actual collection or proof of a globally optimal route. Actual installed UI, phase timings and complete account trading remain post-update acceptance items.
