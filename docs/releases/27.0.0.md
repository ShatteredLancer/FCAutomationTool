# FC Automation Tool 27.0.0: Read-only First Release

FC27 的首个全新安装版本，**仅提供只读准备和诊断，Live 执行保持硬关闭**。本次发布不代表真实 SBC 保存、提交和奖励闭环已验收。

## 本版提供

- 传统 SBC 目标、条件、库存及 FSU 选材策略读取，安全候选预览和材料不足诊断。
- 原 FSU Local 接线、精确 Club 实体只读复核、未决状态检查。
- 独立 Tampermonkey GM 存储、跨标签互斥与安装自检。
- 约 130 KB 的精简 Runner，新安装身份 `FC Automation Tool`，不打包 FC26 工作流或交易模块。

## 尚未开放

- SBC 保存/提交、自动开包、Pick 领取、物品移动。
- Rolling、Swap、Provisions、交易、定时调度及旧 Profile。
- 尚未取得真实网页合同的积分 SBC。

真实库存充足后，另行批准并验证一次低价值 SBC，再以新版本开放已验收功能；本版没有用户开关可以绕过 Live 门禁。材料不足属于安全停止，不会购买卡片或放宽保护。

## 安装

1. 安装 Tampermonkey，禁用旧 Runner、Preview、Acceptance 和 Hot Reload。
2. 安装本 Release 的 `FSU-Local.user.js`（26.09.8），保留原 FSU 名称、namespace 和设置，不同时启用两个 FSU。
3. 安装 `FCAutomationTool.user.js`（27.0.0），刷新 FC27 Web App。新 Runner 不迁移 FC26 的配置、Journal、授权或凭证。

FSU Local 是独立插件，仍保留其原有功能，并不因 Runner 只读而禁用 FSU 自身的手动操作。此次包含价格赛季绑定和 Home 初始化竞态修复；冷启动、设置保留及只读库存抽样已验证，完整一键填阵和价格显示仍有待验证项。
