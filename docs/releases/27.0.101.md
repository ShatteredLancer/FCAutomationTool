# 27.0.101 — Puzzle 降价优化与耗时修复

## 问题与行为

用户诊断中连续四次填阵耗时约8分钟，降价阶段最终因报价过期退回初解。最后一阵已有291张安全候选（含41银、6铜），初解很快可行；主要等待发生在后续查价、搜索和目录方向评估，不能归因于银卡未进入候选或简单扩大节点解决。

- 已有完整报价的库存可行解，在最低总材料价值模式下先做原预算内的1600节点单/双卡替换。单卡按位置分配预算；双卡按位置对轮转并保留枚举游标，避免后排始终得不到检查。新增支出模式保留原双卡遍历。
- 初轮替换之后，可选查询、搜索与方向评估共用30秒窗口；保留最近完成的合规改进。这不是整轮解题30秒承诺，初解、查价和在途请求另有耗时。
- 最终报价过期时，仅重新核价原阵与最终候选，最多44个版本，再按同一来源的新价比较。缺价、认证失败、价源或材料变化仍阻断，不延长报价有效期。
- 政策检查不再重复执行无用的整库诊断统计；FSU设置、账号、锁卡及主阵容保护每次仍读取。评分/化学配置每轮克隆并解析一次，球员事实和完整阵容仍逐次验证。
- 进度显示阶段、规划用时、当前最佳材料估值与待购额；优化失败/限时不再被“填阵成功”掩盖。

另保留本地组合搜索修复：同俱乐部最低人数联合国籍等上限做必要容量剪枝，有限连贯起点共用原预算；不删除合法候选、不扩大节点额度或查询页数。

## 其它累计修改

- Streamlined：旧贡献任务可显式结束安全的未发送余批，保留完整历史与回执；阻断显示具体保护和旧目标原因。外部材料仍先贡献 Club 同版本、独立确认后再移动，未知请求与未决购卡/移卡不自动清除。
- Gallery：纳入 Al Hilal 首任加成差异调查、公开卡片元数据与构造情景回归，没有修改生产计分规则或历史首任记录。
- 修复 Windows 测试模拟服务的换行归一化，使其与现有生产指纹计算一致，不放宽方法审查。
