# 27.0.85 — Gallery 冲级增分路线

## 用法

Gallery → 整体方案 → 规划目标 → **冲级增分（本地计分估算）** → 生成整体方案。

- 在同一候选库比较俱乐部、联赛、国家等当前目录合集。提供“增分性价比”“多增分”“少占本金增分”三条候选路线，可手动选择。
- 逐合集显示现有计算分、目标分、增分、采购/共享卡、周转本金及预计净损耗。“进入俱乐部 / 合集”带入具体数值目标，之后再点原有“生成方案”，不再只传 S 后误判已经完成。
- 不要求升级到下一档才纳入候选：同档内及已达 S 后的改善也可以比较。原来的“拿 token（S → A → B）”仍是默认模式，保留原优先级。
- 两种目标各保留一份本次页面会话内的计算状态。切换目标、进入合集再返回不丢有效结果；收藏/卡池变化沿用局部更新，共享版本变化会影响相关合集。账号/目录变化和实际报价过期仍按原规则失效。刷新或关闭整个插件后仍需重新读取，不新增持久化大快照。

## 计分与成本边界

新增计算分是**完整合集本地分数的增量**，不是 EA 全局 XP，不能据此预测精确等级或还差多少到 Lv.10。不把 token 换算为 XP，不宣称已经领取奖励。

未凑齐人数的合集在此指标下以 0 个完整合集分为基线，不把原来的部分阵容分当成已经获得的完整计分。收集状态未知的合集暂不纳入增分路线；首任加成不确定时，以原完整分数上界比较新方案下界，避免夸大增量。界面保留未知项说明。

同一精确版本若改善多个合集，只计算一次采购/税损，各合集分别计算本地增分。已收集后卖出或 SBC 消耗仍算已有；不是当前持有量，也不重复采购。资金仍按逐卡买入、确认收集、假设卖出到账后周转计算，未实现销售收入不当作真实余额。

沿用 Fodder 快速参考和按需独立核价，参考估算不保证可买或最低价。新增两个数值探测（当前基线上方、约 1.5 倍），每个最多 6,000 次评估/48 beam，只接受完整且有价格的改善；未到探测目标的 best-effort 仍可作为其实际分数候选，不伪造达标。原单合集普通档位结果不改。深度独立查价仍为 24 → 48 → 96 的有界候选，不全目录预查。

## 不变

无新增自动交易、EA 写入、奖励领取或 XP 写入。方案生成只读；购买仍走原明确确认、现价核验、预算/单卡限价、锁卡/主阵容及交易 Journal 恢复。数值目标不混入仅支持 D–S 的联合目标存储。FSU 26.09.10、Puzzle .80–.84、普通 SBC、既有缓存 TTL/保护和未决交易记录不变。
