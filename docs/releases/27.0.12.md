# FC Automation Tool 27.0.12

日期：2026-10-06。Gallery 阶段收尾与累计改动本地提交；本次不推送、不创建 tag 或 GitHub Release。FSU Local 保持 **26.09.9**。

## 本版改动

- 收集未知状态按精确版本隔离：未知卡不计分、不采购，其余明确材料继续规划；读取不完整及已有卡缺分仍停止，不能把未知或有界搜索失败视为全局无解。
- 奖励采用各 Set 自身阈值及奖励，按已达到的档位累计同类奖励。单 Set 方案显示当前/预计等级、累计奖励及差额；各档费用显示本档/累计奖励；联合预算方案可按同类目录奖励优化。奖励不抵扣购卡预算，领取状态仍为未知。
- 增加账号隔离的持久计分缓存、计分协作让步和既有预算内的冗余采购剔除；补齐 Fodder 单/联合规划、复杂条件和动态候选池接线。
- 比价结果在同步重绘及切页后保留；同步状态记录任务/读取阶段、页数和数量；修正长列表 Bulk List 底部操作栏可达性。
- 持久净成本账本记录已确认购买、挂牌及精确售出回执，按实际成交和税后收入计算净成本；缺失/未知售出证据不猜收入，账本失败不重复购买或挂牌。
- 脱敏诊断单独保留交易结果；增加 Gallery 只读检查、方案/费用切页复核和当前构建安装源码/hash 核对工具。
