# 27.0.125 — 库存周黑阵容也按材料价值优化

- 单周黑、仅要求全队最低评分的普通 SBC 已有合规库存解时，「最低材料总值」不再直接保存首个方案。固定同一张库存周黑，只比较通过锁卡、主阵容、评分和 FSU 保护的普通库存卡。以同源有效估价比较，先降材料总值，同价再选贴近门槛的评分。
- 复用单批库存报价与评分分组求解。估值搜索从原节点上限的余量中使用最多 4,000 节点。首个合规方案缺价、报价到期或没有更好解时保留原解，不把未知市值计作零。单独选择「最低购卡支出」时仍可直接使用合规库存，不查价。
- 163/266 离线对照复用截图的 23,650 金币和评分分布，加入模拟的便宜库存后，两种 EA 评分模式均选出 81 分、20,100 金币的阵容。周黑保持同一张，普通材料估值 9,900 → 6,350；不是当前市场价格或原账号库存回放。
- 原购卡和提交路径、不覆盖已有阵容、库存/保存前后精确验证与节点上限不变。没有在真实账号买卡或提交。
