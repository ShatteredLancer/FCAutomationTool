# 27.0.67 — Bound nested Gallery work and resume it without restarting

- Overall planning can now pause baseline scoring, reference validation and deep grade work at an existing cooperative checkpoint when the configured deadline or Stop is reached. It returns completed rows/grades instead of letting an unresponsive nested scorer continue until its input expires. Continue reuses the exact unfinished iterator on the same frozen inputs; invalidation closes it.
- Reuses the existing score memo within each collection, releases completed collection work and never persists continuations to GM storage or analysis JSON. Scoring rules, evaluation order and candidate/node limits are unchanged.
- Only the overall roadmap opts into full binding checks at the beginning, before/after asynchronous yields and before completion. Each inner step still checks the page/account context; immutable inputs cannot change between asynchronous boundaries. Other callers retain the default validation behavior. Expired references or actual account/catalog/material changes still invalidate the result.
- Diagnostics now include the configured planning limit, retained/route counts and explicit expiry/context reasons. Time-limited partial output is distinguished from unexplained blocking. Existing reference TTLs, independent buying quotes, spending caps, protections and transaction/recovery records are unchanged.
