# FC Automation Tool 27.0.3

2026-09-30 按用户要求升版并整理本地提交，收录 27.0.2 提交后的 Gallery 开发及离线诊断能力。本次不推送、不创建 tag 或 GitHub Release；已发布资产不变。FSU Local 保持 26.09.9。

## 主要变化

- Gallery 从占位入口变为分类、集合和卡池浏览：FUT.GG 动态目录优先，Fodder 作为可见回退；按单集合懒加载，不扫描整个球员库。
- 读取 EA 精确版本的 collected/gradingScore，缓存按账号、Persona、平台和赛季隔离；已收集、当前持有和 First Owner 分离，缺失事实不当作零或已拥有。
- 按 Enhancer 的原生 EA 展示链生成球员卡面，保留特殊立绘及闪卡字段；联赛、俱乐部图标复用页面资源。卡面失败仅文字回退，不用头像套壳。
- FUT.GG 平台价格串行按最多 50 版本分批，5 分钟缓存和失败退避；部分失败保留成功批次及旧报价，旧报价只作快照，不参与有效成本规划。
- 显示参考等级、分数区间、下一档差额、计分阵容和加成说明。提供指定等级的单集合与多集合联合规划、精确版本费用去重及可选预算；有界搜索未找到方案不误报全局无解。
- Settings 支持 HTTPS 转发端点保存/清除和脱敏诊断 JSON 导出。最多持久保留 300 条 Gallery 事件，记录请求阶段、来源、路由、状态、计数、缓存和退避，不保存 URL、凭证、账号标识、响应正文或完整球员对象。
- 补齐离线浏览器场景、检查器代理配置和恢复记录；既有 Puzzle、购买与材料/事务保护不改，FSU 源及维护版本不改。

## 验证与边界

升版前完整回归已通过 304 文件 / 3444 项，生产面板和 Gallery 离线浏览器检查通过。真实安装页已有目录、Arsenal 卡池/收集进度、原生卡面及筛选/返回的分场景证据；最终价格、目标/联合方案、账号切换及手机导航的真实安装验收仍待完成。升版后的完整复验结果在下方补记，不能把历史安装结果当作 27.0.3 已安装。

用户提供的 2026-09-30 诊断 JSON 确认真实环境导出成功：FUT.GG 经 HTTPS forwarding 约 239ms 后出现 NETWORK_FAILED，随后 Fodder 返回 200、126 集合。没有 FUT.GG HTTP 回执，不能归因为 403、限流或账号问题；具体端点连通/权限原因和清除转发后的恢复尚未确认。浏览器/系统代理与 FCAT 的 HTTPS forwarding 设置是两种机制。

Gallery 自动采购、兑换、奖励领取、EA 权威等级和真正奖励优化未完成。现有等级/成本方案是参考计算及本地有界候选，不承诺全局最优或可领收益；关注目标仅存当前页面内存。通用市场、定时交易、库存整理、Routine 和 Rolling 仍未接通 FC27 业务。既有 Puzzle 的真实批量买断、旧记录续购仍按原计划待验收。

## 恢复路径

安装本地新构建后，若仅使用浏览器/系统代理且未部署 HTTPS 转发服务，应清除 FCAT 的转发端点，保留浏览器/系统代理。Gallery 请求失败会保留安全错误与退避；不连续点击绕过退避。再次读取后可从 Settings 导出日志离线调查。

后续先在稳定登录会话核对最终卡面价格、目标/联合方案、筛选/返回和账号隔离，再实施 Gallery 采购闭环；不借升版消费金币、清理购买回执或提交 SBC。详细场景与恢复点见 [Gallery 计划](../FC27_GALLERY_PLAN_ZH.md)、[购买审计](../FC27_FSU_BUY_PARITY_AUDIT_ZH.md)。
