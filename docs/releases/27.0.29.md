# 27.0.29 FUTBIN 参考平台与廉价卡接口调查

## 本版

- Settings 新增 `FUTBIN Reference Platform`：默认 PS，可按账号选择 PC。
- FUTBIN 单卡与评分分页报价均遵守设置；缓存、进行中请求和失败冷却隔离平台。
- FUT.GG 仍按 EA 当前账号平台读取，EA 真实交易平台不变。不因报价平台切换
  修改旧购买审批、预算、单卡上限、候选池或 Journal。
- 新报价与审批保留 FUTBIN 参考平台，刷新时拒绝混用另一个平台的报价；旧记录
  缺少该字段时维持原语义与冻结价格，不强制清空或重新批准。

## 调查

已验证 FUT.GG 公开接口：

```text
https://www.fut.gg/api/fut/market/27/cheapest-by-rating/v2/overview/?platform=ps
https://www.fut.gg/api/fut/market/27/cheapest-by-rating/v2/overview/?platform=pc
```

经本地代理匿名 GET 均返回 200 / JSON，13 个评分段（81–93），PS 135 / PC 134
条候选，含精确版本 ID 和价格。无需 EA 登录或凭据；不承诺所有网络可直连。
当前 FUTBIN cheapest 网页返回 403。能力、缓存与未来接入边界见
[调查记录](../FC27_CHEAPEST_BY_RATING_ZH.md)。FUT.GG overview 本轮未接入生产规划，
不把它描述为已实现全市场最低价或已修复重复版本的批次策略。
