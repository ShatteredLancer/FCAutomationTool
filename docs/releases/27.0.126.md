# 27.0.126 — 积分 SBC 补卡估价和缺货换卡

- 规划时不再把一张孤立的市场最低报价当作可以重复购买的整批供给。对同评分、同贡献积分的市场版本，低于第三低报价的版本各最多估一张，剩余需求按真实版本价格和合格库存比较。
- 同一批可以一起贡献授权的不同版本，已买入的孤立低价版本各计一次。
- 191/264 原日志：已确认 25,895 / 40,000 分、35 张、8 批，原预算 22,080，已花 6,000。两张候选在 800／900 的实际查询上限内多次返回零挂牌。没有待确认回执或已购未贡献材料。
- 只把成功返回零挂牌的版本，在同一已批准方案里标为缺货。后续批次、暂停后继续及重新打开不再搜索这些版本；已有旧任务无需迁移或清理。搜索拒绝、报价异常、未知交易结果不能当成缺货。
- 按已确认积分、已有材料和原剩余预算重算，只能用原已批准候选及其原单卡上限。没有合规替代就暂停，按「生成方案」重新审核；不会自动增加授权、省略回执或重复买入／贡献。
- 191/264 离线回归沿用日志的进度、原预算、两张卡空搜索上限，历史回执与替补模拟。相同场景旧路径对缺货版本搜 34 次；新路径各搜一次，17 张模拟替补补到 40,005 分，累计 21,300，原 35 张不重投。也验证无替补／重载时零新增买入与贡献、超价不下单。没有在真实账号执行。
