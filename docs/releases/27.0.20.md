# FC Automation Tool 27.0.20

基于 ad/main `9342be5 / 27.0.19`，保留其报价提速、路线、库存物化和交易主逻辑。

## 更新

- 执行进度固定在底部按钮上方，长列表滚动时仍可见。点击后立即显示准备/核对状态；
  搜索显示候选、限价和尝试次数，采购显示数量/花费，贡献显示 EA 已确认积分。
- 等待步骤持续计时，部分批次显示预计剩余等待；停止/暂停/失败保留原因和确认结果。
  计时不代表 EA 请求成功，进度不会把计划积分当作已提交积分。
- 独立、默认展开的库存消耗清单：完整姓名/评分/来源/估值，区分将消耗与已消耗。
  纯库存模式随选中批次更新，市场模式保持冻结路线；50 张分页和底部查看入口仅只读。
- 按用户另行批准，启用 FSU 手动 Lock 与当前 EA 主阵容保护，覆盖首发/替补/预备。
  不代表所有历史保存阵容都受保护。读取未知或不完整时停止；规划与贡献请求前复查。
- 旧 Journal 不改写、不清除。旧方案只有通过当前保护复核才继续，不沿用旧版忽略锁卡
  的许可；历史已确认贡献保留。进化、特殊卡、身份/回执和未知事务保护不放宽。
