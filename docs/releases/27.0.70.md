# 27.0.70 — Retained global Gallery plans and cooperative optimization

- Overall planning now compares three bounded alternatives over one shared candidate pool: more tokens (default), lower forecast loss and lower revolving capital. The confirmed priority is S, then A/B. Shared exact versions are purchased once in the forecast; bounded same-tier shared combinations are considered. Execution order and turnover calculations follow the same tier priority. These are inspected-scope alternatives, not proof of a mathematical or whole-market optimum.
- Collection-level calculation is a background scheduling mechanism, not a set of unrelated shopping lists. Independent 40ms work slices preserve exact continuations, while completed candidates feed the global comparisons. Reference checking and deep quotes interleave instead of waiting for a complete catalog prepass. Global comparisons themselves can resume without restarting at the first option.
- Returning from a club in the same tab/account retains the global plan. Only changed collections and affected shared versions lose old candidates/work; unaffected calculations and still-fresh quotes remain. Acquired-then-sold versions remain ever-owned. Reference/deep mode switches reuse the same reference session. Explicit full rebuild, account/season/catalog-rule changes still invalidate. There is no new large GM snapshot or cross-reload restoration promise.
- Final boundary checks withdraw stale progress/pools even when their material key has not changed, and preserve within-collection turnover order when a changed route is removed. Remaining capital is recalculated without silently reversing the original per-card funding order.
- Overall-only exact-input summary caching (64 cloned results), an exact total-only search evaluator, shared scorers and equivalent-option deduplication reduce repeated CPU work. Final detailed scoring, rules, tie behavior and search limits remain intact; other callers retain their defaults. A controlled repeated-input sample reduced 24,600 checkpoints to 820 and 59ms to 13ms. That is not a live-account or whole-run speed claim.
- The view/export distinguishes all alternatives, visited/local-score task status, inspected/completed/pending collections and local reconciliation counts. Unverified S targets are not declared impossible. Forecast capital remains the user's input assumption, not a claim that unsold cards returned coins. Club handoff still passes only Set ID/grade. Actual quote freshness, balance, spending limits, player protection, transaction recovery and journals are unchanged.
