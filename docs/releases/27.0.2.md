# FC Automation Tool 27.0.2

本版本整理 FC27 Puzzle 解题、概念卡补卡与购买修复，以及原生 FCAT 工作台。2026-09-29 按用户要求升版并准备本地提交；本次不推送、不创建 tag 或 GitHub Release。FSU Local 保持 26.09.9。

## 主要变化

- 原生 SBC 侧栏一次点击解题，联合现有库存与市场候选，把已有卡和待购概念卡填入同一阵容；采购目录、报价和失败恢复按账号缓存，减少重复请求。
- 选材读取原生品质条件，金卡默认最高 82 且可配置；最低银卡＋至少两金时保持两金＋其余银卡，不为凑分放宽材料保护。补卡单卡报价上限可配置，缺货版本可排除后重新规划。
- 修正概念阵容同步、保存回执恢复，以及用户清空、部分修改、切换账号后的记录处理；当前页面、精确身份与未决事务共同参与核对。
- 独立参考 FSU 的概念卡购买实现：FUTBIN 参考价、原生搜索、默认五次可配置查价、选单与等待行为；单卡明确失败继续其它卡，未知成交保留回执防重复购买。新增前台购买进度，购买与 SBC 提交保持独立。
- FCAT 入口移入原生左侧导航；工作台分为 SBC 解题、Gallery、市场、自动交易、库存、Routine、滚卡、活动记录、设置九个标签，移除原生页面内重复标题。
- 补充参考插件行为一致、需求澄清、计划恢复和场景验收约束，保留 FSU MIT 归属及购买差异审计。

## 验证与边界

升版前相同功能源码已通过完整回归（293 文件 / 3290 项）、离线浏览器交互、FSU 补丁重放及产物一致性检查。专用浏览器已验证原生 FCAT 导航、九标签切换、离开返回、重复标题消除和窄桌面滚动；标签切换不触发业务请求。升版后的复验结果在下方补记。

真实概念保存、恢复及部分市场读取已有分场景证据；最新购买实现的真实批量买断、旧账号记录续购仍待实测，不能宣称全环境与 FSU 完全等价。390px 实机遇到 EA 自带 Resize Window，手机导航以及脚本晚加载兜底的原生页面化仍待完成。

Gallery、通用市场、定时交易、库存整理和 Routine 当前只有规划中的模块入口，滚卡暂缓；标签存在不代表业务功能已实现。可选 AI 助手仍为开发检查能力，不因本次升版进入生产界面。本次提交验证不消费金币、不提交 SBC。

后续先沿用当前账号与阵容记录，由用户主动点击购买，验证价格、前台进度、单卡失败继续、成交替换及中断续购；详见 [购买审计与恢复点](../FC27_FSU_BUY_PARITY_AUDIT_ZH.md#本轮修复验收与恢复点)、[Puzzle 稳定性计划](../FC27_PUZZLE_STABILITY_ZH.md) 和 [工作台计划](../FC27_AUTOMATION_STUDIO_PLAN_ZH.md)。
