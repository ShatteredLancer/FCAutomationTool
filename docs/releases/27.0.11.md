# FC Automation Tool 27.0.11

日期：2026-10-05。当前累计改动的一次本地升版提交；不推送、不创建 tag 或 GitHub Release。FSU Local 保持 **26.09.9**。

## 本版改动

- 统一公共报价与购买上限：Settings 支持 FUT.GG / FUTBIN / Both，购买/挂牌共用参考来源，默认复用有效缓存；可设置购买固定/百分比溢价和每卡尝试次数。禁用源不读取，缺价不回退 EA 估价，不自动放宽已批准上限。
- Gallery/Puzzle 统一前台购买窗口：标题/停止/关闭对齐、顶部进度、紧凑逐卡清单、折叠报价详情；失败卡可编辑本次上限并显式重试，已成交或未知回执保留核对恢复路径。
- Bulk List 布局与报价修正：保留原购买回执成本；纵向设置/六列表格、百分比即时定价、手动覆盖；挂牌与购买重试箭头统一按 EA 相邻合法价档。
- Gallery 定时挂牌与自动重挂接入：须用户主动启用，重挂范围可选本批或全部未售，默认本批；按原起拍/一口价重挂、最多两轮，保留停止、恢复和互斥。关闭页面不是后台常驻任务。
- Puzzle 修复公共报价联合规划参数不一致、候选排序覆盖搜索路线、只优先少买卡的问题；按待购公共报价总价选方案，有价时比较一张与更便宜的两张修补，保持既有搜索/请求预算。
- Gallery 优化计分缓存与规划反馈，补 Fodder 复杂规则及动态卡池兼容；删除无效的脚本内 HTTPS forwarding 设置，域名代理分流由浏览器/代理客户端处理。
- 诊断补成功填阵后的待购总价、逐卡公开报价、数量和搜索完整性；补齐相关工程约束、修复计划及恢复记录。
