# 27.0.91 — 轻量交易观察第一版

## 入口与使用

FCAT → **交易观察**（原“自动交易”占位页）。这不是自动抢购程序，也没有防封承诺；新功能只读取公共参考价、提供提醒和保存手填记录，不调用 EA 搜索/买入/移动/上架/重挂。

[EA 官方规则](https://help.ea.com/en/articles/ea-sports-fc/fc-rules/)明确限制 bots、automation 和 auto-buyers。本版未新增这类市场调用，但这不等于对既有脚本或账号作合规/免封保证。

1. 展开 **资金与利润设置**，核对后保存。默认只是 Sam 本轮的预填例子：起始金币 40,000、试仓总上限 10,000、保留金币 30,000、单卡上限 2,000、目标净利润 150、每卡跌价缓冲 100。所有金额可手改，不把 10,000 写成程序硬上限。默认余额不是 EA 实时读取值，首次保存前不发机会提醒。
2. 展开 **添加观察球员**，粘贴 FC27 FUTBIN 球员页链接，或填写精确 EA 版本 ID 与名称。FUTBIN ID 和 EA ID 不同；链接会用已有公开最小接口核验对应关系。也可“读取已加载卡片”后按名称选择：这只读 Club/Transfer/Unassigned 本地缓存和既有公开卡片事实，不刷新或扫描完整库存。
3. 点 **刷新报价**。沿用公共报价来源启用设置；不会暗中开启被禁用的来源。双源是否有效分别显示；交易观察按实际 Console/PC 市场读取，不把另一市场参考设置拼入趋势。定时观察需明确点击启动，最多每五分钟尝试刷新，离开观察页/关闭面板/账号变化停止；刷新后不自动恢复。
   提醒为页内提示，不是系统推送；浏览器后台节流、网络故障会造成延迟，不保证实时。
4. 从 EA 官方界面手动核价，输入 **当前原生买价 / 保守可卖价**，点击 **核价并评估**。两项手填核价五分钟有效。机会成立时显示页内提醒、未读数、建议买入上限和预计税后利润；同一标的/买价/卖价/上限在三十分钟内不重复提醒。提醒不是已成交或自动下单，过期提醒显示为历史。
5. 实际买卖由用户在官方应用操作。勾选“已实际买入/卖出”后再点 **只记账**；这些记录不是 EA 成交回执。保存预算不改历史，移出观察名单不删除持仓。可以导出不含账号上下文/原生实体/其他日志的本地 JSON。

## 价格与资金口径

- FUTBIN/FUT.GG 分源、同版本、同平台记录。源更新时间和本地读取时间不混淆；有源时间就用源时间做图，否则明确为采样观察时间。缓存命中不增加样本，不回填不存在的历史。小时/日/周窗口不足 80% 覆盖或不足两个样本显示“样本不足”。首日没有完整周线。
- 买入建议约为 `保守卖价 × 95% − 目标净利润 − 跌价缓冲`，向下取保守金币档位；再受单卡、剩余试仓额度和保留金币约束。仅为显示建议，最终原生价格上下限/档位由用户确认，不生成交易许可。
- 保守卖价取手填卖价与两源当前参考价的较低值；源偏离超过 15%、源时间过旧/未来、报价失效、近期可观测小时跌幅超过 8% 时仅观察。第三方价格不代表当前可成交挂单，挂牌消失不当成交，预计收益不写入实际收益。
- 账面金币 = 手填起始金币 − 手填买入 + 已手填卖出的税后收入；试仓占用只算未售持仓成本。已实现盈亏由实际手填卖价按 5% 税保守取整计算，不自动计入新的起始值，避免双算。账外交易和实际到账需用户自行核对。

## 消息与策略边界

支持多来源 X 原帖链接、备注、爆料/已确认/已上线/落空状态；列表中的账号是观察示例，不是命中率排名。尚无自动 X 采集、可信度统计或独立消息去重推断；用户应核对原始出处，同源转发不算独立确认。消息不影响任何交易许可，也不自动推荐传奇 SBC 材料仓位。FC27 积分材料策略需按目标 SBC 原生资格/贡献分另行核验，不以评分或 Gallery 分直接替代。

## 体积与数据上限

不引入图表库、SDK、X 客户端、全目录爬取或新依赖，曲线只用原生 SVG。每账号笔记独立 Web Lock；最多 20 个观察版本、每源每版本 120 点、7 天滚动分桶、100 条手填交易、30 条原帖、40 条提醒，单笔记序列化硬界 750,000 字节。旧采样和提醒可有界淘汰；手填交易满额后停止新增，不静默删历史。锁卡、FSU/现有设置、Gallery/Puzzle/Streamlined 和待核对事务不进入该笔记，也不由它清理。

此前 64MiB 报错对应扩展消息体限制，不等于 user.js 文件有相同上限。Chromium 的[扩展消息测试](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/chrome/browser/extensions/api/messaging/messaging_apitest.cc)直接覆盖该报错。脚本和存储仍会共同影响启动，不能据文件小就承诺永不超限。
