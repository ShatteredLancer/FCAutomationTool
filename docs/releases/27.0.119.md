# 27.0.119 市场交易任务启动和挂牌

EA Web App 更新到 11502 后，FCAT 可能在用户点击启动时提示「EA 原生交易接口尚未通过校验」。本版合入 27.0.115 至 27.0.118 的库存识别、市场候选读取和 SBC 选卡改动，同时补齐交易任务依赖的会话与竞拍接口校验。启动再遇到未知方法时，导出诊断可看到对应阶段和方法。

- 纯出售任务按 Transfer List、Unassigned、Club 的顺序处理符合条件的卡。每次收到 EA 对该卡的成功回执后继续处理下一张，移卡和挂牌之间的额外等待为零。EA 响应时间仍计入实际耗时。
- 等待定时时间的任务遇到保活失败时显示警告，并继续等待执行。实际交易失败时仍按对应错误处理。
- 更新脚本并刷新 Web App 后，可在市场交易中启动原任务并沿用持仓和交易记录。

具体的回归场景见[挂牌顺序与耗时](../FC27_TRADING_LISTING_CADENCE_20261119_ZH.md)和[交易接口兼容记录](../FC27_TRADING_START_COMPAT_20261119_ZH.md)。

合并后全量测试通过 6838 项，FC27 专项通过 2002 项。完整离线 Chrome 回归、发布产物校验和本地打包均通过。原账号的定时挂牌和实际耗时仍待实测。
