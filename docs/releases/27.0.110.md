# 27.0.110 — Gallery 计分、速度和集合界面对齐 Enhancer

Gallery 现在按 Enhancer 27.0.1.8 的规则选择展示阵容和计算加成，分类下的 Set 顺序及信息布局同步调整，并补齐 NWSL 等图标。

## 本版内容

- 修复原生拍卖实体在 createItem 后才附加 owner 信息的时序问题；旧未经核实的首任观测保留为待核，不再作为确定加成。可只读复用当前账号在本机 Enhancer 中已有的 v2 首任历史，手工声明和经过验证的原生证据优先；不创建、修改或上传 Enhancer 数据。
- 展示选阵改为基础分初解与逐标签候选，替代旧8000次交换；同值加成选择最大单组，包括 Multiples。深度规划仍保留，未知字段仍显示区间，缓存随计分引擎版本失效。
- 同输入 London、Serie A、Bundesliga、NWSL 四组结果与 Enhancer 一致。NWSL 用户截图30张可精确复算289,021；用户换卡后已确认与EA一致。展示候选不保证全局最高分，也不冒充EA当前保存阵容。
- 198集合 Node CPU 控制从6724ms降至150ms，约45倍；这是计算基准，不代表整个联网加载过程提速45倍。
- 大类和Set使用公开目录原顺序；卡片显示单徽标、D–S彩色进度与门槛、已收集/所需张数、总分（+加成）和奖励。整卡/键盘进入详情，关注按钮保持独立；桌面、平板、窄屏对应三/二/一列。
- 补齐NWSL、MLS、沙特、法甲slug与稀有度/Starter卡壳；俱乐部名称未命中可使用公开队徽奖励的精确teamEaId。旧排序缓存仅一次正常刷新恢复源序，失败保留原快照和退避，不重置账号卡池。
