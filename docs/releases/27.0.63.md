# 27.0.63 — Gallery overall roadmap, revolving capital and level milestones

- Gallery → **整体方案** automatically considers the current catalog; manual joint-target selection is no longer required to see a whole-Gallery route. It shows current/target grades, incremental catalog tokens, exact missing/shared versions, revolving capital, forecast loss and cumulative purchases separately. Entering a collection carries its target grade into the existing planner; it does not buy, list or claim anything.
- Capital is a per-card turnover forecast: buy → confirm collection → sell and receive proceeds → continue. A route can have cumulative purchases above its starting funds. Funding checks include tax erosion and ordering; a single unaffordable card does not reject all other collections. Optional loss ceiling and explicit resale-price scenarios remain estimates, never sale receipts or spending authority.
- Uses the existing scorer, grade solver and public price providers. The low-loss-per-incremental-token route is bounded, not a market-wide optimum. Partial coverage, unknown collection facts, candidate-limited pools and missing prices remain visible. Stop/continue retains checked grades and selected options. Expired quotes and account/catalog changes invalidate results.
- Exports an allowlisted local analysis JSON with deduplicated public versions, collection facts, evidence/price freshness, grades/rewards and the forecast. It excludes account identifiers, native item identities, credentials and transaction journals. It does not persist another large GM snapshot, scrape social-media guides or upload data to an AI service.
- Adds **画廊等级与奖励**. A reviewed read-only EA Objectives call exposes Gallery level milestones and reward descriptions. Live readback confirmed a redeemed level-5 milestone and a level-10 **1 of 5 Holographic Base Hero Player Pick** description. Missing completion state stays unknown. The observed response does **not** provide exact current Gallery level or XP; an optional account-scoped console note is clearly labeled as a local manual record, not an EA update. Season-pass levels and Gallery tokens are not substituted for Gallery level.
- Original per-collection/joint purchasing, listing/readback/relisting, budgets, per-card caps, locks, active-squad protections and pending journals are unchanged. The roadmap does not automate sale settlement or launch a cross-club trading loop. Refreshing level information never claims rewards or writes XP.
