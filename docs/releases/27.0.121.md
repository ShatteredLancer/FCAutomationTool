# 27.0.121 — 普通 SBC 缺周黑时可确认补卡

适用于要求 **1 张 TOTW、带评分但不带化学要求**的普通 SBC，例如 10x 82+ Upgrade（163/266，11 人、最低 81 评分）。

1. 点「FCAT 解题填充」。有符合保护设置的 Club/SBC 仓库周黑，继续库存优先，不查市场。
2. 库存没有合规周黑时，最多读取三页明确的 TOTW 目录。若原有十张材料和一张合规市场周黑能满足挑战，阵容只增加一张待购概念卡，并显示预计金币。参考价不是实时成交价。
3. 查看「FCAT 确认买 1 张周黑」按钮上的上限。点击确认后才重新核价并尝试买入。不会自动放宽评分、单卡限价、方案报价上限或金币预算；没有合规挂牌就停止。
4. 成交后按物品 ID 核对回执及 Club 交付，重新验证 11 张材料。恢复会复核已确认项，不重复扣款或再次投入材料；FCAT 不会自动提交本次 SBC。

锁卡、主阵容、联赛排除和库存的不可交易筛选不变。其余 SBC、画廊、积分解题与交易功能不走这个专用路径。

离线验证：全量 6,815 项通过、42 项跳过；FC27 专项 1,984 项通过、37 项跳过。Chrome 验证只有真实点击确认才传入上限；163/266 模拟成交回执不明、保存回执丢失、报价过期、错卡、超价和保护变化，均未重复下单。未在真实账号买卡或提交。
