# 27.0.52 Puzzle ordinary-profile chemistry pruning

## Live evidence

The supplied 27.0.51 diagnostic again shows Set 65 / Challenge 105 stopping after 50,000 owned-search nodes over 123 safe candidates. The phase counts are unchanged from 27.0.50: 45,193 combination nodes, 4,807 complete-combination bounds, and zero placements or full evaluations. The market repair route also exhausted 20,000 local checks after three catalog pages (59 distinct versions, 44 usable). The export does not contain the live chemistry profile snapshot or the account's private safe-card identities, so it cannot prove either that this guard was the only live blocker or that a valid safe squad exists.

## Change

The 27.0.51 partial-combination bound required **every** EA chemistry profile to use the ordinary model. A previously observed FC27 chemistry snapshot includes extra Icon/Hero/special-card profiles even when all safe candidates are ordinary cards. Those unrelated profiles disabled the bound before search began. The bound now selects the profile for each candidate rarity using the same rule as the complete squad evaluator, and enables pruning only if each actually used profile is ordinary. Missing, incomplete, or nonordinary candidate profiles still disable this optimization. The bound remains optimistic; it never removes cards from the safe pool or replaces final requirement/chemistry verification.

A same-shape 123-card regression with a known legal 22-chemistry squad first reproduced the 50,000-node stop when a nonordinary profile for an unrelated special rarity was present; the corrected path finds and fully verifies the squad within the original cap. A separate unit test confirms that an unrelated profile is ignored while a nonordinary profile applying to a candidate rarity still disables the bound.

The 50,000-node owned search, three catalog pages, 20,000 repair checks, FSU/lock/active-squad protection, material rules, pricing, purchase/save/submit and receipt contracts are unchanged. Synthetic and offline validation do not establish live-account success; a new diagnostic after updating is needed.
