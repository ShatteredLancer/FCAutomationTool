## Evidence

## Changes

- Targeted Club validation applies the pile requirement to the exact selected entity, not to unselected extras in the response. Every response row still needs valid identity and definition, factory consistency and no duplicate identity. Only the frozen selected ID/version may satisfy the batch. A selected card in the wrong pile, mismatched definition, missing copy or protected card remains blocked.
- Post-contribution independent readback no longer treats an unselected returned card's pile as evidence against consumption. If any consumed exact ID is still returned, **in any pile**, confirmation is blocked; malformed/conflicting rows still stop. Contribution receipt, fresh progress and durable confirmed-batch semantics remain mandatory.
- Export only bounded, fixed mismatch counts for this validation branch; no player IDs, account details or raw responses. Existing unsafe states remain blocked.
- Show an actionable Chinese message for `FSU_NOT_READY` without changing the FSU readiness checks or permitting a write. The screenshot alone does not justify relaxing them.
- Retain 27.0.47 cooldown and reviewed GET backoff, 30-minute purchase approval, budget/per-card caps, FSU/lock/squad protection, unknown-write handling and confirmed-batch skip. Gallery, ordinary Puzzle and FSU code are unchanged.
