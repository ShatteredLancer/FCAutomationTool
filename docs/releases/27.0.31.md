# 27.0.31 贡献与恢复诊断

## 本版范围

- 修复积分采购贡献链路只显示统一恢复错误、丢失底层阶段/原因的问题。
- 分别记录材料校验、发送异常、规范化响应状态/HTTP、回执校验、读回、
  本地收尾与恢复失败；保留原始的固定错误码，不记录自由异常文本。
- 固定的 EA 响应分类转换为可导出的 FC27 诊断码；不改变实际响应的
  accepted/rejected/unknown 分类，也不将 HTTP 200 当成贡献已确认。
- 失败阶段进入原有有界事务摘要，重新规划和报价刷屏后仍可导出。
- 仅导出阶段、错误码、状态、数量和积分；不导出账号、物品/成交 ID、
  指纹、原始回执、响应或凭据。诊断同步抛错/异步拒绝都不影响交易。

## 没有改变

预算、单卡限价、最低材料成本、FSU/锁卡/进化/主阵容保护、请求与恢复
决策、持久化 Journal 合同都保持不变。仍然同版本每批最多一张，确认
消耗后才可跨批复购；本版没有新增“整个方案禁止重复版本”的限制。
不自动重复购买/贡献、不清未决记录、不把核对失败当作已成功。
FSU Local 仍为 26.09.10。

## 现场证据与边界

27.0.30 用户诊断确认三次买入/入 Club，共花费 1,650 / 批准 1,840；
第一批贡献已确认 430 / 1,250，之后有一笔待核对操作、两张已购卡
未结清。两次恢复仍返回统一错误。旧 JSON 未记录实际失败阶段或
底层回执，不足以确定服务端是否提交、响应是否丢失或哪项读回失败。

本版修复诊断缺口，不宣称上述实际贡献故障已修复。
