## 修复

- 原 guard 要求 Squad ID > 0，误拒 EA 可用的编号 0。现在允许数字 0，但必须
  由当前 Persona 缓存中的匹配原生实体证明 `_isActive === true`，并通过完整卡位/
  物品 ID 检查；Service 默认 0 本身不构成已就绪。
- 未加载、未启用、标识错配、名单残缺/未知仍停止；负数、NaN、Infinity、字符串
  不转换、不接受。诊断补启用状态阶段和异常数字类别，不导出具体身份。
- 缓存复用仍只限此前已核验的同账号/阵容，且 FSU 名单未变；未知首次读取不回退。
- 手动 Lock、主阵容首发/替补/预备、规划后变化及请求前保护保持开启。
- 未新增 EA 请求，未改选材优化/报价/预算/采购/贡献/恢复或 FSU 脚本，不清旧记录。
