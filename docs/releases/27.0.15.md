# FC Automation Tool 27.0.15

日期：2026-10-09。修复 Gallery/Puzzle 购买初始化的 EA 方法指纹兼容问题；FSU Local 保持 26.09.9。

## 原因与改动

- 用户 27.0.14 诊断中，Gallery 整批在购买初始化返回 `FC27_TRANSACTION_METHOD_UNREVIEWED`，买入 0、花费 0；旧日志未记录失败方法和实际指纹。
- 本次匿名读取 EA Web App 公开 build 11414，抽取原生 `UTItemService.prototype.bid/move`。两者 SHA256 与旧表不同；解码字符串并统一混淆变量名后，与 10 月 3 日已审核实现一致。用真实函数源码重放，在修复前复现相同阻断，修复后通过。
- 按具体方法新增精确兼容指纹，同时保留原始和 10 月 3 日指纹。没有自动批准未知指纹，也没有更改价格上限、重试预算、授权、Journal、购买/入库逻辑。
- Gallery 现在单独记录 `purchase-method-check`，导出允许的方法名和实际 SHA256；同步日志刷屏后仍保留。诊断异常不替换购买错误，不导出源码、账号或凭据。

公开来源与完整对照见 [工程记录](../REFACTORING_MILESTONES.md#2026-10-09-27015-购买方法指纹兼容与-gallery-诊断)。用户导出缺少实际指纹，因此此次确认的是最新原生 EA 方法可复现该故障；账号页面上如另有插件包装，仍需新诊断确认。
