- 解决 163/266（10x 82+ Upgrade）库存已有合规周黑但普通材料不够时，只显示「库存未找到阵容」的问题。按不同卡片版本计数，保留一张合规周黑；先找最少补卡数，再验实际 11 人评分。只有队伍评分仍不足时，才考虑替换额外的普通卡。
