# 27.0.92 — 自动候选与按需 X 原生线程采集

## 从哪里开始

FCAT → **交易观察**。打开此页就按预算自动筛选，不需要先填写球员。首次仍请展开“资金与利润设置”，核对并保存：默认起始金币 40,000、试仓总上限 10,000、保留金币 30,000、单卡上限 2,000、目标净利润 150、跌价缓冲 100；全部可调。这些是手填账面假设，不是 EA 实时余额。

- 每个候选显示精确版本链接、来源、关注理由、**等待买价、卖出参考、税后模型差额、退出条件**。不是让用户按当前参考价直接买入。
- 点击“跟踪本轮候选”或单卡跟踪。公共双源报价触及观察买价时，可以在没有手填买卖价的情况下发页内提醒；它只提示重核原生买卖两端，**不代表利润成立**。原有手填原生买卖价后的价差评估仍保留。
- 一批最多六张，各一张买价上限合计不超过剩余试仓额度；已手填未售持仓会占用额度，不预支尚未售出的回款。首次未保存资金设置只给参考预览，不发机会提醒。
- 买价参考五分钟有效；换账号、资金/持仓/手动线索变化后不沿用旧建议。跟踪保留原报价时间与 TTL，不把跟踪动作变成新样本。
- 实际买入后仍由用户勾选并记账。持仓提示原卖出目标、税后保本价和当前参考盈亏；达到目标时核价卖出，税后浮亏达到原缓冲或买入满六小时则复核退出，不自动延长等待或加仓。六小时是首版短线复核规则，不是预测市场会在六小时回升。

## 自动候选的范围

默认读取 FUTBIN 的 80/82/84 普通金卡各一页，并在已启用 FUT.GG 时交叉核对最多十二个精确版本。只展示最多六个预算内观察候选；未启用第二来源时明确标为单源，不暗中修改来源设置。

X 采集中，作者明确点名的 EVO 候选可额外触发最多三个名字的定向公开查价。使用已经实测的同一 `getFilteredPlayers` 路由的 `name` 参数，不扫 EA 挂单；按结果唯一的人名和精确版本核价。同名多人、缺价、特殊版本未覆盖等不猜买价；普通铜/银/金候选仍受同一预算和利润条件约束。作者只提名字而未确定版本时，仍标版本/完整条件待核，不据此声称 EVO 合格。

双源偏离超过 15%、相对收盘参考大跌超过 8% 或上涨超过 15% 的候选暂缓；收盘参考的统计窗口未知，不冒充 24 小时收益。成交量、挂单深度和 trader 持仓未知，不编“流动性/拥挤度”分数。本版是有限样本的低价短线观察，不是全市场最优、META 排名、周五必涨策略或收益保证。

原始公共响应不存入 GM；投影候选缓存只在内存中、五分钟有效、最多八份。正常读取三页，含作者点名时最多额外三页；HTTP 429 按市场退避五分钟，换名字也不绕过退避。手填记录、锁卡、设置与待核对交易日志不清理。

## X 自动采集：点击才运行，不开定时

按 Sam 选择，X 采集只在点击 **“采集 X 线索并筛选”** 时运行，不随打开页面或五分钟价格观察自动运行。需要独立本机采集器；仅升级油猴不会安装 Grok 或自动启动本机服务。

### 首次连接

1. 电脑已安装并登录 Grok Build（本轮实测 1.0.70），本项目使用 Node 22–24。
2. 在本项目目录运行 `npm run trading:intel`，保持采集器运行。
3. 在交易页展开“连接本机采集器”，填入本机控制台显示的配对码并保存。配对码不要对外分享；它不进入交易记录导出。
4. 点击采集按钮。预计需几十秒到数分钟；超时明确报错，不自动重试产生调用。关闭采集器即停止提供此入口。

默认复用环境代理，也可只读识别 Windows 已安装 `grok.cmd` 中的静态本机回环代理；不会执行该包装脚本。其他电脑可通过 `FCAT_INTEL_PROXY` 指定本机 HTTP 代理，或用 `FCAT_GROK_EXE` 指定 Grok 程序路径。没有 API key 也可复用当前 Grok CLI 登录；模型额度/实际费用由用户自己的 Grok 账户承担。界面显示的 CLI 模型估算不是平台账单，也不保证包含全部工具费用。

### 读取与证据

- 关注源：FutSheriff、FutPoliceLeaks、Fut_scoreboard、AsyFutTrader；这是采集范围，不是可信度排名。
- 原生 X 关键词搜索后，挑选最多两条 EVO 线程执行 `x_thread_fetch`，并按 `conversation_id:原帖ID from:作者` 查作者补充回复。作者在回复中点名的卡可成为线索，不必等他公布完整 EVO 条件。
- 先前 `--tools web_search,web_fetch` 白名单会同时过滤原生 X 搜索，已移除。采集任务改用客户端工具禁用清单与权限规则，禁用普通网页、文件、命令、MCP 和子任务，仅让 Grok 使用原生 X；不会读取 OAuth 文件或把密钥放进油猴。
- 采集器还会读取**本次隔离任务自己的调用日志**，检查已完成的真实原生 X 调用；缺少调用证据时不采纳生成结果。只有原帖线程和对应作者会话查询都已执行，才标“作者回复线索”。不把模型回答中自称“查过线程”当证据。
- 使用 X 雪花 ID 核对发布时间；同帖/同文去重。普通网友评论不当作者回复，转述不自动算独立确认。主题名、模糊提及、仅有赛季标签不自动变成候选版本；只有原帖文字中有明确点名引文才定向查价。
- 线程读取/搜索可能截断或漏结果，因此仍不声称完整读完所有回复；未知版本、资格和条件明确保留未知，爆料也不当官方上线确认。过旧线索不触发当下候选定向查价。

### 本机边界与体积

采集器只监听 `127.0.0.1:17864`，固定 POST 路由加配对码，不开放远程监听、通配 CORS、任意命令或任意 URL。请求不携带 EA 账号、库存、金币余额、预算、成交记录或锁卡。只返回小型公开消息投影；成功结果缓存十五分钟，并发刷新合并，失败退避一分钟；单进程每日最多二十四次采集，无自动定时。

生产声明仅新增精确 `@connect 127.0.0.1`。构建策略只为该配对只读入口增加精确例外，其他回环/内网/通配权限仍拒绝。采集程序在 Node 侧，不打进油猴；没有新 npm 依赖、X SDK、图表库或新的 EA 买卖/提交接口。
