## Change

The earlier partial chemistry bound credited selected cards with nation/league/club support from cards elsewhere in the full safe pool, even when those cards were already skipped by the ordered search. It also credited multiple flexible selected cards that could all fit only the same few positions. The bound now counts selected group members plus the maximum available in the remaining suffix, and caps selected in-position scorers by a maximum matching to distinct formation slots. It still ignores off-position losses in group counts, physical duplicates in the suffix and conflicts between future choices. These are optimistic relaxations: pruning only occurs when no continuation can meet the native chemistry minimum.

For chemistry-target searches, candidate traversal now prefers cards that can cover less-supported formation positions before using broad identity frequency. This changes order only, never candidate eligibility. Storage preference, native requirements, FSU/lock/active-squad protection, full chemistry and requirement validation, 50,000-node owned search, three catalog pages, 20,000 repair checks, pricing and purchase/save/submit/receipt contracts remain unchanged.

A synthetic 123-card case with the same requirement shape and a known valid 22-chemistry squad first reproduced the 50,000-node stop with two-position decoys. The new path found and fully validated the squad in 4,925 nodes. Pure bound tests cover ignored unused identities, overlapping positions and sparse ordered selections across 24 deterministic seeds. This is an offline search regression, not proof that the user's live protected inventory contains a valid squad.
