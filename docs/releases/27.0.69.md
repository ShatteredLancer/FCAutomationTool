# 27.0.69 — Demand-driven Gallery optimization and scoped price reads

- Deep overall planning now publishes a locally verified Fodder reference overview before independent price requests. It prioritizes collections with token upgrades by forecast cost per added token, then quotes candidate combinations and rule/score/price-diverse alternatives in bounded 24/48/96 tiers. It no longer prices the entire missing catalog before doing any planning. The changed checkbox explicitly describes **on-demand**, not exhaustive optimization; untested versions may be better.
- Quote reads and cooperative computation share the configured per-run time limit. Quote batches contain at most 24 versions and use a deadline of at most 15 seconds or the remaining run allowance. In-flight readers keep the original shared queue/cancellation/cooldown contracts; stopping or reaching the limit retains completed read-only results and paused work for same-page continuation. Still-fresh exact versions are reused across collections. No network concurrency or retry limit is increased.
- The roadmap requests only the user's selected reference authority, rather than waiting for an optional comparison source. Existing normal Gallery dual-source displays, actual purchase/listing sources, preferences, approvals and quote cache lifetimes are unchanged.
- Reference overview and independently priced results are displayed/exported separately. Expired independent results are removed without renewing their timestamps or discarding unaffected routes; remaining turnover/loss totals are recomputed. The original club handoff still passes only Set ID and grade. Buying rechecks prices and retains all existing spending/protection/transaction rules.
