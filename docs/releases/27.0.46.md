# 27.0.46 Fixed 30-minute purchase approval window

## Evidence

The supplied 27.0.45 diagnostic pauses at 110,950/115,000 points with `PURCHASE_APPROVAL_EXPIRED` at 10:03:32 local time. Recovery then completes 115,000/115,000 at 10:04:38, spending 58,400 of the approved 61,180 coins, with zero pending writes and zero unconsumed purchases. This confirms that run completed after recovery; it is not a network-timeout diagnosis or evidence that every long run is interruption-free.

## Change

- Increase only the production Streamlined procurement **default execution approval** from 10 minutes to a fixed **30 minutes** after the user's approval.
- Preserve an explicitly supplied deadline, including a shorter one. Searches and activity do not renew the deadline; reaching it still pauses before another purchase.
- Do not raise the approved budget, remaining budget or frozen per-version maximum. Continue reducing search caps to the actual remaining budget and rejecting above-cap offers.
- Quote expiry, HTTP/native request timeouts, fresh identity/protection checks, durable journals, unknown-write recovery and all .45 archival safeguards are unchanged. Recovery itself grants no new buying authority. Gallery, ordinary Puzzle, FSU and material selection are unchanged.

## Verification

- Regression first failed on .45 when the production execution/procurement composition reached minute 11 or just before minute 30.
- Clock-driven tests cover continuation past minute 10, expiry exactly at/after minute 30, an explicitly shorter deadline, a search crossing the fixed deadline, rejection of an above-cap offer, and the unchanged remaining-budget cap. No real wait or EA transaction is used.
- Focused tests: 181 passed across four execution/procurement/purchase/cross-recovery files.
- `npm run verify`: 420 files, 4,982 passed, 39 existing skipped. Syntax, undefined-variable, configuration, architecture/profile, FSU patch/release, build, metadata and root/dist equality checks passed.
- Complete offline Chrome suite passed, including Streamlined recovery/archival, purchase-result controls and independent Gallery/Puzzle/FSU checks. No real-account buy, move, contribution or reward claim was used. These checks do not replace live acceptance of the longer run.

This does not automatically resume an old unknown request or remove transaction evidence. Live acceptance of the longer window remains pending after updating.
