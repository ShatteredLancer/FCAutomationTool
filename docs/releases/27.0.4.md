# FC Automation Tool 27.0.4

2026-10-01 按用户要求升级并提交当前改动。本次为本地 Git 提交，不推送、不创建 tag 或 GitHub Release。FSU Local 保持 26.09.9。

## 主要变化

- Gallery 按分类首页、集合列表、卡片详情分层；移除首页“全部”，重新进入回到分类页，详情提供置顶返回。分类与集合使用图标和紧凑奖励展示。
- 收集状态改为账号隔离的共享历史与增量合并，沿用 EA 原生查询和认证；提供后台同步进度、停止与当前集合优先读取，关注不再影响同步资格。分批计分及让出主线程减少切换卡顿。
- 使用 EA 原生卡面，修复 Hero/Holographics 特殊立绘的异步加载、重绘及资源生命周期；失败时文字回退。修复卡片标记遮挡置顶导航。
- 集合标题仅展示一个有效队徽，重绘复用选择；等级轨道按已知分数下限显示，不再因收集人数不足或分数为区间而清零。紧凑奖励只汇总可解析图标的 EA EventToken，避免把物品 ID 当数量。
- 大集合采用按 Gallery 分数排序的最高 100 个候选，按集合要求选取计分卡；明确候选范围，不能据此宣称全卡池最优。完善目标、联合规划和缓存复用。
- 接入 Gallery 采购会话、前台进度、逐卡回执与恢复，以及购后精确版本收集查询；真实消费验收仍待完成。
- Puzzle 无市场候选时提前结束无意义的搜索，保留准确停止原因；有效候选搜索耗尽仍保留搜索上限结果。补齐 Gallery、采购、同步、响应性和安装器回归及检查命令。
