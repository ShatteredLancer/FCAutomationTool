# 27.0.90 — Gallery 冲分满员校验与跨合集依赖

## 现场与证据

用户报告 SC Freiburg（德甲）要求 15 名可计分球员，但有时方案只有 14 人。当前目录该合集要求确为 15 人。

用户进一步明确问题在新加的整体冲分模式：英雄合集的方案只给买一张，但买后仍缺两人。页面已刷新，原整体分析没有导出，故此次先做模型/缓存/续算/共享路径自检，不要求用户恢复已丢失快照。

此前对 .85 诊断的离线回放只涉及四个单合集输入，均为 Set 21。第一个输入包含 7 张已收集可计分版本，原求解器返回购买 8 张的完整 15 人阵容；其后三个输入包含 15 张可计分版本，返回已达到目标。该诊断没有保留用户看到 14 人时的原始清单；本轮发布未重新获得已丢失的整体分析快照，故不把“已有 1＋采购 14”的解释当作已证实的现场唯一原因，也不声称已重现那次少人计算。

确定的界面缺口是：原候选标题只写采购张数，没有交代复用哪些已有卡及最终计分人数；整体路线“复用”实际指跨合集采购共用，并非库存复用。合成 15 人场景（已有 1＋采购 14）在原生产 UI 的人数说明断言失败，新版通过。

独立自检发现一个可用原生产求解器确定重现的少人路径：五英雄、两张已收集、两张仅持有但 `collected:false`、另缺一张，旧冲分实现把持有当作已确认收藏，从而给出“只买一张即可完整”的计划。恢复 .89 的原求解器运行新回归会失败；修复后这些待同步卡既不补槽，也不重复采购，等待原生收藏状态确认。该路径与用户描述吻合，但缺少原始整体快照，仍不认定就是现场唯一原因。若五英雄中两张确已收藏、另外三张完全缺失，原正常分支本就会补三张，只有一张可买时不会给完整方案。

另有两处确定缺口：冲分汇总仅信任候选 `reached/full` 标志，注入“声称达标、实际仅三人”的异常候选仍会被纳入五人路线；共享采购控制中，三张补卡可被资金规划拆成“本步新购一张＋前序两张共用”，旧输出未明确前序尚未执行的依赖关系。

## 修改

- 原求解器及公开参考核验保留最终选中计分版本的 ID 见证；不复制完整卡片对象。单合集列出“已有可计分 X 人＋本方案采购 Y 人＝最终计分 R/R 人”，可展开查看复用的已收集卡。
- 冲分独立区分已确认收藏与物理持有；仅持有未确认的卡不计为已填槽且不重买。跨合集可传播同版本已确认收藏证据，但持有状态不升级为已确认；原生确认变化即使 held 未变也使相关计划失效重算，清账号会话时清除证据。深度优化、续算和单合集数字目标保持该口径；普通档位/token 选材语义不改，也不强制变更用户配置的库存去向。
- 冲分候选进入整体路线前独立核对所有计分槽位，不再只信任分数达标标志；组合选择和恢复也拒绝人数证据缺失/不完整的冲分候选。未满员只给待核实原因，不计为可执行增分路线；普通 token 模式原规则保留。
- 新的纯本地人数检查按精确版本、正数基础分和明确已有/可购买状态计数。零分卡、未知状态、重复或外来版本不补人数，不使用汇总 `collected` 数量冒充计分人数；明确 EA 0 分不借公开正分覆盖。不同版本的同一球员仍按原 Gallery 规则分别处理，已收集但卖出/SBC 消耗的版本仍保留。
- 真正不满员或见证不一致的保留方案显示提示，不展示购买按钮；点击购买时在人、账号、材料和原报价绑定检查后再次校验。旧计划没有计分见证时只做可用人数核对，明确不冒称选中了哪些卡；未清历史、交易或设置。
- 整体方案区分“本批新买 / 跨合集共用”，另列已有/需补/最终计分人数。共享卡保留为前序待购/待确认依赖，不当成已收集；列出依赖合集、完整补卡清单。删去前序或报价失效后重算成本归属及依赖，不能继续借用已撤去的采购。分析导出增加完整补卡版本、前序共用与依赖合集及人数汇总，不增加已有卡身份明细。
- 后续单合集诊断沿用现有白名单字段记录要求人数、已有计分人数、采购计分人数及最终人数，不扩日志环或导出原生账号数据。
- 更正 .85 发布说明的“国家”措辞；当前按实际目录中的俱乐部、联赛、Rarities 等合集规划，并无独立国家合集入口的确认。

## 保留边界

基于最新 main `7067211` / 27.0.89，未恢复旧版本生成产物或覆盖 .86–.89 的 Puzzle 修复。改动限 Gallery 人数/收藏口径、依赖说明和相应回归；ad 的原 Puzzle、Streamlined 和 FSU 主逻辑不改。

不改变计分公式、候选排序、目标分数、搜索预算、首任上下界、token/S→A→B 或冲级路线目标。人数检查是 O(卡池＋计划) 的本地边界检查，不新增网络请求。检查针对完整单合集目标的候选方案，不拦截手动选卡/分批购买，也不要求每一批交易买满 15 张。原预算、单卡限价、报价 TTL、锁卡/主阵容、收集/购买/挂牌 Journal 和所有未知回执保护不变；不因“需要 15 人”而强制多买已收集版本，不自动买卡/移动/挂牌/确认主机合集。
