日期：2026-10-09。合并远程 `a31398c / 27.0.17` 后提交累计缓存与规划修正。用户确认使用 27.0.18，避免原请求 27.0.16 导致版本倒退；FSU Local 升为 26.09.10。

## 改动

- 保留远程 27.0.15-27.0.17 的购买方法兼容、成交回执恢复、Gallery 历史获得与当前持有/计分分离逻辑。版本与生成脚本冲突通过更新版本并从合并源码重建解决，不覆盖远程业务源码。
- FCAT 大型 collection、目录及逐 Set 卡池采用无损 gzip/base64；启动迁移自身 GM 缓存，跨账号且无需登录，写前检查并发变化、写后回读核对。公共旧聚合缓存仅在逐 Set 副本全部确认后置空，不清交易 Journal、设置或计划。
- FSU 26.09.10 压缩自身双 slot Club chunks，兼容旧原始值，逐 chunk 核对后才写 manifest；factory、exact scoped capture、provisional、12 小时快速路径和提交前定向校验合同不变。上游 origin 不改。
- 启动增加有界诊断与可选 UI 初始化异常隔离，区分未注入与模块启动失败；生产 Settings 不恢复安装自检入口。
- Puzzle 按待购总价继续比较原有最多三页/60 候选范围，只以严格更低方案替换；保留原搜索节点/请求限制、保护、报价来源和保存事务。不承诺全市场最低。
- Streamlined 新规划默认比较库存估值＋待购总价，保留最低待购与最少卡选项及旧冻结计划。补全原生实体类型/可交易字段、库存诊断和 FSU Only Untradeable 读取；混合路线市场读取失败明确阻断，不静默变成库存方案。Transfer List 材料执行仍未接入。

## 更新与恢复

安装根目录 `FCAutomationTool.user.js` 和新版 `dist/FSU-Local.user.js`。如果旧组合载荷已超过 64 MiB，首次仍需要临时停用其中一个脚本，让另一脚本先完成启动迁移。例如先停用 FCAT，仅运行新版 FSU，等待 `[FSU_CACHE_MIGRATION]` completed/failed:0，再启用 FCAT 刷新并确认两项 Gallery 迁移。无需清缓存、卸载、登录或删除 Journal。
