# 27.0.95 — 后台采集器与审核后自动交易

## 使用入口

### X 采集器

Windows 项目目录运行一次 `npm.cmd run trading:intel:shortcuts`，在桌面 `FCAT X Collector` 建立：

- `Start Collector`：隐藏后台启动；提示可关闭，不需挂着黑窗口。
- `Collector Status`：查看运行/空闲/采集状态，不调用 Grok。
- `Stop Collector`：认证停止自己的采集器及当前 Grok 子进程；保留配对码。已发出的模型调用可能产生费用。

也有 `trading:intel:start`、`:status`、`:stop` 命令。重复启动不会再开第二个进程；不设开机自启、计划任务或采集定时器。旧前台服务没有停止接口时需先关原窗口一次。后台日志不打印配对码；原前台命令保留排查用途。新认证 `/v1/shutdown` 只有固定停止操作，不接受命令、路径、PID 或任意 URL。

交易页还有“停止本机采集器”。这只停止 X 采集；EA 自动交易由自己的停止按钮控制。

### 整批投资方案与自动交易

交易页顶部“本轮投资结论与自动交易方案”：

1. 等候选分析完成，先看综合结论；没有合格机会明确暂不买。
2. 设置本轮总资金上限（预填 **20,000**，不是固定值）和最低留存金币，点“生成可审核交易方案”。
3. 查看整批精确版本、数量、买入硬上限、固定目标卖价、税后情景收益与依据；不想买的卡可移除重算。方案生成不买入。
4. 审核并勾选同意后，点“确认并开始自动交易”。原生市场重新核价、核余额/容量后，按限价购买本方案新卡、转至转会列表、按固定目标价上架一小时。
5. 查看逐卡进度。上架不等于卖出；只有原生明确 `isSold` 且实体/挂牌 ID/成交价匹配才计已实现收益。运行期间每分钟仅只读核对已挂单成交。
6. 可停止新操作，EA 已有挂单不撤回。离开交易页或刷新不自动继续；重新打开保留本机记录，可先只读核对，再明确批准继续。

首版是有限批次低买高卖，不是无限抢卡机器人：最多六个普通版本各一张；没有上限内挂单则跳过，不临时加价或换卡。已买但未卖完的上一批不能被新计划覆盖。过期不自动重挂、降价或止损卖出；可在官方应用处理后核对，缺少完整回执仍保留记录，不用“清缓存”解锁。

本轮审批与旧观察笔记估算分开；旧手填未售持仓也扣占用额度。执行前以原生余额与保留金币再次核验。已有设定、旧审批、锁卡、主阵容卡和所有其他待核对 Journal 不修改。没有默认新增买卖授权，升级、开页或 X 刷新都不会启动交易。

## 信息与执行边界

- 现有双源公共参考价用于套利筛选，实际买入仍须原生挂单满足上限。参考价不是保证能卖出的价格，情景收益不是收益承诺。
- X 仍是未确认线索，缺完整 EVO 条件/精确版本的帖子不直接驱动付款。没有把 leaker 的口头可靠印象当作统计胜率。
- EA 官方活动/完整 EVO 条件、市场指数与更广泛交易讨论是后续证据层拓展方向，本版没有声称已自动接通这些额外数据源。
- 自动化存在账号风险，不承诺防封。后台 X 采集器不负责运行 EA 交易；真实交易页需要保持打开和登录，后台标签仍受浏览器休眠影响。
