# 27.0.114 — 交易任务、恢复流程与原生球员搜索

本版收录此前累计的交易改动，并合入远程 27.0.111–113 的 Puzzle 选卡、SBC 明确拒绝后恢复及 Streamlined 重载期限修复。

## 主要变化

- 交易任务支持立即购买、竞价或两者结合；多评分分别设置买入、竞价、挂牌价格，保留只买不挂。竞拍必须确认赢得后才计入持仓，未知回执不重复出价或购买。
- 持仓出售可按评分和仓库持续扫描可售卡，直到暂停或停止；每轮结束五分钟后复查并加入新卡，精确实体认领和既有保护保留。
- 挂牌明确拒绝后暂停当前任务，避免原卡反复重新排队。新增挂牌的起拍价按 EA 档位低于一口价一档，并同时检查上下限；原价重挂保留历史价格。
- 旧挂牌记录可通过鲜读核对收尾，未决记录提供显式隔离、备注和再次核对入口；保留原账本、资金／容量预留和防重复约束，不自动删除未知成交或解除暂停。
- 交易保活遇到明确的认证401后，最多一次原生认证和 telemetry，再做一次只读复核。停止、账号变化、失败与未知交易保护继续生效。
- 姓名搜索直接复用 Enhancer Trader 使用的 EA 原生控件：姓名／评分两列、整行点击、放大镜和清空。登录前面板已挂载时，延迟到打开选卡窗口再创建原生控件；选中姓名后仍选择精确版本。
- 删除评分价格编辑中的“批量填价”，保留逐行编辑、EA 价格档位步进、隐藏列与范围外价格保存。
