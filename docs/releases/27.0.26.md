## 本次修改

- 用户明确选择新方案默认预留 **15%**：在原所选路线单卡上限合计上增加备用额度。
  例如 41,800 + 6,270 = **48,070**。金额在执行前显示、可编辑，可信执行点击才授权。
- 备用额度不是花费目标。原有最低总材料价值排序、授权池内换卡、单卡冻结限价及
  所选库存物品范围不变；更便宜的版本可用时仍优先买它，不为填批次多付溢价。
- 旧执行预算仍冻结，不自动加 15%。重新生成新方案后可明确批准新预算；结清记录
  先归档、成交/消耗证据保留，未知或未消耗回执不通过清空记录来绕过。
- 本批已经没有可继续加入的不同版本时，立即贡献，不再固定空等。旧等待只计时，
  等完没有新增搜索或材料；重复单版本 38 批会产生超过 10 分钟授权的无效等待。
  兼容设置/Journal 字段保留，界面说明其为上限、已搜尽时跳过。原生请求节奏和
  真正缺货时的有限重试不变。
- 新诊断导出实际 `approvedBudget`、`spent`、`remainingBudget`，不再仅靠方案估算
  推断审批金额。不导出账号、物品 ID、原始 DTO 或凭证。

## 连续流程审查：后面仍可能停在哪里

| 阶段 | 当前行为 / 仍保留的停止边界 |
| --- | --- |
| 缺货换卡 | 仅在已批准市场池和剩余预算内按原经济目标重算；15% 不保证任何候选有挂牌 |
| 单卡限价 | 每张卡保持原冻结上限；总预算备用不允许买更贵的同一张卡。价格上涨超出旧上限需新方案审批 |
| 公开报价 | 生产入口已接通每次选卡的公共报价读取，可刷新过期报价；刷新失败、来源禁用或仍过期时暂停，不换源、不续假时间 |
| 库存和容量 | 只消耗预览已选实体；其他库存卡不能自行加入。未分配容量耗尽且本批无材料可先贡献时暂停，不自动丢卡/出售 |
| 同版本重复 | Club 同版本不能在一批重复购买/入库；先确认该实体贡献，再买下一张。现在不再为这条必要顺序空等 |
| 贡献后进入下一批 | 以实际回执/服务端积分为准，保存已消耗身份；不要求已消耗卡仍在 Club，也不把计划分数当作完成 |
| 10 分钟授权 | 仍保留。特别大的目标或缓慢 EA 响应仍可能到期暂停；进度保留，无未决回执时可一次执行点击续跑，本轮未擅自延长授权 |
| 真实未知回执 | 买断、移动、贡献结果未知或记录写入失败时保留证据并恢复，不重发、不擅自再付金币 |
| 保护 / 身份变化 | FSU 手动锁卡、进化、主阵容、账号/SBC/设置变化仍复核；不是通过关闭这些检查来继续 |
