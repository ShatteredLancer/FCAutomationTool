# 27.0.50 Puzzle repair-quality coverage and search diagnostics

## Evidence and scope

The supplied 27.0.49 diagnostic for Set 65 / Challenge 105 records 123 safe owned candidates, an 80.6-second owned search exhausted at 50,000 nodes, and a repair route exhausted at 20,000 checks without a plan. All three catalog pages were Gold (team 21, leagues 19 and 13), reused from cache; 59 distinct versions yielded 44 usable candidates. The catalog reads caused no new request in that run. This is not proof that this account has a safe solution, and public solutions do not establish local availability.

The Challenge requires at least Silver quality, at least six Gold players and 22 chemistry, alongside the screenshot's league and nation limits. A synthetic five-Silver/six-Gold near-solution at 21 chemistry is completed by one in-position Silver, but the old repair query planner asks only for the six-card majority Gold tier. This is a demonstrated blind spot; whether it caused the account's actual failure remains to be verified.

## Change

Keep the three-page catalog limit, reserving one read-only page for the weakest-chemistry non-dominant quality tier and its league when that league is allowed. If no valid secondary query exists, keep all three pages for the original dominant tier. No quality requirement is weakened; every proposed squad still passes full material, requirement and detached EA chemistry validation. FSU, locked and active-squad protections, purchase budget and per-card caps, purchase/save/submit transactions and receipt handling are unchanged.

The owned-search diagnostic now reads the solver's nested `plan.search` counters and strategy-attempt count instead of silently omitting them. It exports only aggregate counts, not player identities or inventory.

## Verification and residual limit

The regression first failed on the old all-Gold query route, then passed with a Silver page while the same synthetic Silver purchase produced a fully validated chemistry-24 suggestion. Syntax, ESLint, configuration, architecture, FSU-patch, build, root/dist and FSU-release checks passed. The complete test suite passed with four workers: 421 files, 5,023 tests passed and 39 pre-existing skips. Two default-parallel verification attempts each had three unrelated test timeouts; the same tests passed in isolation and the full suite passed with bounded workers. The offline Chrome self-test passed. These are synthetic/offline checks, not live EA account acceptance. The 50,000-node owned search, three catalog pages and 20,000 repair checks remain finite; a valid plan outside the sampled pool or beyond those search bounds can still be missed. A fresh 27.0.50 diagnostic is needed to assess the live outcome.
