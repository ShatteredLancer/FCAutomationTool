# FC Automation Tool 27.0.13

日期：2026-10-07。本次整理 Gallery 累计修改并本地提交，FSU Local 保持 26.09.9。

## 改动

- Gallery 交易增加独立 Fodder 购买/挂牌界面，默认保留 Enhancer 风格；Settings 可选择风格和购买后发送 Club 或 Unassigned。恢复交易沿用本批冻结去向。
- Fodder 提供本批购买价格区间和尝试次数、Market/Bought for 挂牌基准、累加调价及仅发送 Transfer List。公共报价选源、购买上限、精确回执和未知结果恢复规则保持有效。
- 修复重试购卡后窗口空白、waiting 卡没有继续入口、异常结果丢失报价和尝试信息。重试返回 Fodder 双栏进度窗口，完成或停止后显示结果；已购卡不重复购买。
- Gallery 方案同时满足分数和计分卡数量，支持已达 S 但缺卡的集合继续补卡；补充低成本多卡升级候选，改善 Holographics 高价方案，并分批读取超过 250 张卡的报价。
- Settings 安装与交易设置并排，报价设置移至底部；补充双风格隔离、窄屏、长列表、停止及续购的浏览器回归。
