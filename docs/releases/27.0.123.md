# 27.0.123 — 保留周黑，按目标评分选更便宜的普通卡

- 单周黑、仅评分条件的普通 SBC（例如 163/266）仍先尝试库存。如已有合规周黑但要买普通卡，围绕全队目标而非单卡评分上限选候选；以 81 分、单卡上限 82 为例，查 82–76 档，最多三个 EA 候选页／60 个版本。公开价有效时复用对应评分页，不延长报价有效时间。
- 在已报价、符合保护的候选中，按评分分组，避免反复枚举评分相同的球员。按 EA 公式验算后，先比总购卡价，同价选更贴近目标评分的组合；仍不承诺全市场最低价。
- 保留一张已拥有的合规周黑。单卡评分和价格上限、预算、锁卡、主阵容与成交保护不变；必须确认才买，不自动提交。新版本不自动覆盖旧阵容，也不重买既有成交。
- 按日志里的 8,600 金币问题构造了离线回归。加入低档候选后，同样 11 人、81 评分、1 张库存周黑，合成报价从 8,600 降至 5,600。两种 EA 评分模式均通过；不代表原阵容完整回放或当前市场报价。
