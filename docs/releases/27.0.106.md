# 27.0.106 — Puzzle 默认比较材料总值，保留已保存目标

## 用户确认的目标

默认由「最低购卡支出」改为「最低材料总价值」：库存也按当前选定价格来源估值，允许在原采购预算内多买便宜卡，以避免无谓消耗较贵库存。不是按85分设置新的禁用线；若高分卡确实便宜或组合需要，仍可在原保护范围内入选。

已经明确保存 additional-coins 的设置不自动改写。在设置页及现金优先方案结果中明确说明库存不计新增支出，并给出 FCAT 设置 → 解题优化目标 → 最低材料总价值 → 保存 的位置。没有保存目标的默认读取改为 material-value；已有评分、单卡限价和查价次数原样保留，不写入迁移或清空记录。

## 修复范围

- 默认目标与设置页初始选择、缺省回读一致；保留显式现金优先模式，不改变已有用户选择。
- 设置页在两种目标切换时立即解释口径；保存反馈含实际目标。以前保存的现金模式回读后仍显示现金模式及切换提示，不在后台改成材料模式。
- 原生解题结果区对现金模式给出切换位置；如果用户要求材料总值但报价不完整而回退现金可行性，明确提示「本轮未完成材料总值比较」，不把回退误说成用户主动选择。
- 匿名诊断增加 requestedObjective，与原 effective objective 分开。字段仍有原字符串长度和记录总量限制，不包含账号/物品身份或敏感原文。
- 已有完整合规库存方案、但没有估值服务时，不为了无法进行的估值比较多读EA目录；保留方案并明确未知估值。补卡不足与已有公共价格服务的材料比较路径仍沿用原合同。
- 比较器、原单源价格/有效期/部分估值边界、5万→10万→20万可行性预算及本地降本上限均不改变。预算、逐卡限价、最大采购数、FSU、锁卡/主阵容、预留及买入/贡献防重复保护不变。
