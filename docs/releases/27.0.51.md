## Change

A synthetic 123-card case with the same challenge-rule shape and a known fully valid 22-chemistry eleven also stopped under 27.0.50: 43,451 combination nodes, 6,549 full-combination bounds, zero placements or evaluations. The blocker was the absence of a chemistry feasibility check while a combination was still being assembled.

The new pure partial-combination bound uses the verified ordinary chemistry thresholds. For each selected card it computes a maximum score from all safe distinct definitions sharing its nation, league and linked club; cards tied to the same unique compatible slot cannot both score. For each remaining slot it assumes the best available suffix card, ignoring competition between slots. These relaxations can only **overestimate** achievable chemistry. A branch is pruned only when even this optimistic total is below the native requirement. If the ordinary chemistry model, identity or position data are not verified, this new pruning step is skipped. Every candidate remains in the pool, and a found plan still passes the existing complete EA requirement and chemistry validation.

The owned-search cap remains 50,000 nodes; the procurement catalog and check caps remain three pages and 20,000 checks. FSU, locked and active-squad protection, material policy, pricing limits and all purchase/save/submit/receipt contracts are unchanged.
