# 27.0.109 — 市场任务分档定价、原生选卡与会话维护

市场交易任务现在可以按评分分别配置买入上限与挂牌价，从 EA 原生姓名资料选择精确卡版本，并在已启动任务等待定时执行期间维护会话。

## 本版内容

- 纳入此前已提交的 P1–P6：账号任务列表、固定名单／条件选卡／持仓出售、独立买卖规则、明确启动后的串行执行与回执恢复、重挂和持仓移交、独立买入／卖出时段，以及 FCAT 各市场入口共用的请求额度与暂停信号。
- 条件任务可按评分设置独立买入／卖出价格。空白或半填档位跳过，当前范围至少一档完整；采用 EA 价档箭头，保存／复制／重开保留配置，执行前再次核对实际评分。按原价重挂保留原价，按规则重挂才重新定价。
- 姓名搜索使用 EA 已加载的静态资料；选择球员后再读取精确版本，每页读取20／展示5，最多100，不下载全市场。现有排除名单复用，精确版本与基础球员ID不混用。
- 已启动的运行／等待任务共用会话维护，空闲3分钟读取一次认证 `/user/credits`；近期成功的实时库存读取推迟检查。不消耗市场搜索额度，不新增GM缓存。显示保活状态与最近在线时间；401／限制沿用共享暂停，其他检查失败暂停本轮，停止／账号变化在实际发送前复核。
- 保留既有预算、材料保护和未知成交／移卡／挂牌回执；会话检查成功不会清除旧回执或重新授予交易权限。
