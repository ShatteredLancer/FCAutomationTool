4. 没有可用历史方向时，继续针对原昂贵卡群读取相关分页，优先具体身份过滤，而非重新从首屏开始。无历史不等于停止降本探索。

6. 这次覆盖搜索另有最多 20,000 节点，而不是再给每页 50,000。基础与覆盖搜索最多 70,000 节点，方向分析另记最多 24,000 hintNodes。新增计算用消息任务让出，未改交易请求节奏；不是仅提高原节点上限掩盖候选不足。
