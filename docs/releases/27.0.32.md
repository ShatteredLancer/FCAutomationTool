# 27.0.32 — 积分 SBC 默认优先消耗现有材料

## 原因与范围

用户指出 Gold Re-Roll 用四张 Storage 卡即可凑够 1,250 分，原规划却推荐购卡。
之前默认比较“库存估值＋待购金额”，Storage First 仅为末级平手排序；
它会保留估值较高但不可交易的普通材料，转而花金币购买低估值版本。

本版仅修正 Streamlined Points Solver 的默认规划，参照普通 SBC 的库存使用逻辑，
不将传统 SBC 的 11 人阵容/化学算法直接用于积分挑战。

## 行为

- 默认策略为库存优先：合规 SBC Storage → Club → 显式启用的 Unassigned/Transfer → 市场缺口。
- 当前层不足时保留该层全部合规材料，再求解下一层；当前层足够时不加入低优先级材料。
- 库存足够时不请求库存估价或市场目录，待购支出为 0。估值未查保持未知，不补零。
- 库存不足时保留库存实体，只针对剩余积分使用原有带报价/限价的市场求解器。
- 最低总材料价值、最低购卡额及最少卡数仍可显式选择；仅市场/仅库存范围保留。
- 旧 schema 1/2 的历史默认在读取新规划设置时映射为库存优先；新保存为 schema 3，
  允许显式选择旧经济目标。不会修改旧冻结 plan、Journal、批准预算或未决记录。
- Only Untradeable、FSU 金卡范围、特殊卡/进化/锁卡/主阵容、精确身份及未知回执保护不变。
- 不改普通 SBC/Puzzle、Gallery、FSU、原生交易节奏和每卡/总预算规则。
