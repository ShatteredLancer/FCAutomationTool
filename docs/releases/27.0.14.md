# FC Automation Tool 27.0.14

日期：2026-10-08。本次整理当前 Gallery 与 Streamlined SBC 累计修改并本地提交，FSU Local 保持 26.09.9。

## 改动

- Gallery 方案计算默认时限提高到 30 秒，Settings 可按账号配置 5–300 秒，单集合、联合规划与剩余目标重算沿用该值。
- “各档费用”改为每档独立计时；超时后保留该档结果并继续下一档，显示当前档位、耗时和搜索进度。超时不代表确认无解，返回集合时保留各档结果。
- 正式 Settings 移除“安装与多标签检查”整块；存储、互斥锁、Journal 和恢复保护保持不变。独立 Acceptance 构建保留开发验收入口。
- Streamlined SBC 接入库存＋补卡/纯补卡多路线、冻结公共报价和购买上限、动态购买/贡献批次及独立采购恢复记录。库存与补卡评分上限分开配置，不再用库存上限筛除市场材料。
- Streamlined 路线只展示积分、待购金币、上限、卡量和预计批次汇总；批次详情提供放大的 EA 原生卡面、姓名、积分、报价及库存标识。
- 补充规划计时、设置持久化、Streamlined 市场/采购/恢复和浏览器交互回归。
